# Playable-parity backlog

[NWN-13](https://linear.app/nwnanalog/issue/NWN-13/complete-playable-parity-with-the-base-native-client) is the parent for 46 prioritized child issues: 42 current parity scopes and four deferred full-client scopes. Existing particle replacement issues NWN-5–12 remain related work, without duplication.

This is a scoped source/evidence audit, not a claim of exhaustive fresh binary execution or a percentage complete. Missing functionality, partial implementation and acceptance gaps are different. Read later accepted evidence before reopening a historical missing-feature claim.

## Completion contract

- Exercise the normal native entry with active base/server resources and unchanged original-server authority.
- Verify original and replacement clients together, including what both players see and independently received/exported outcomes.
- Complete original UI and programmatic surfaces, available actions and selected/disabled/pending/failure states.
- Cover cold/warm entry, prolonged play, cancellation/rejection, pending resources/effects, repeated travel and reconnect.
- Verify complete scene/effect visibility and representative loading/frame consistency at matched camera, input and settings.

The fresh socket-free batch passed 82 of 90 tests; all eight failures reproduced the handoff proof-size defect in NWN-15. Original Markdown evidence paths now resolve through the [archive manifest](archive/manifest.json). The audit hashes describe the pre-cleanup notes, not these summaries. Raw reports remain unchanged. Newer performance evidence is summarized separately in [performance](performance.md).
