# NWN-72 pose field-read reduction

`NetworkMotion.pose()` now reads `state.render` once and `state.orientation` once before constructing the same position/rotation Dictionary. The original line read those Dictionary fields three and two times respectively. No callback or state write occurs between the original reads. The edit removes **three Dictionary field reads per pose call**, while adding two typed local assignments. It does not change motion integration, facing requests, animation clocks or authoritative state.
