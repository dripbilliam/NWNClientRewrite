# NWN-75: original area tile-update Scene services

Pinned `nwmain.exe` SHA-256 `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. This follows the other Scene virtual calls in the connected `P` major-4/minor-`0x14` packet after the [tile replacement](area-tile-replacement.md). The packet flags and tile count gate these services; the static route is not evidence of per-frame execution. Exact callsite edges are in [the supplement](area-tile-update-scene-services-ledger.json).

When the decoded tile count is nonzero, the handler calls Scene virtual `+0x78` at `0x14076f0d9` before replacing tiles. The installed Scene vtable `0x140d8dd30` maps this to `CAurScene::ResetAreaTileFading` `0x1400d30b0`. That wrapper enters `RenderInterface::BeginScene`, invokes Scene virtual `+0x250=Scene::ResetTileFading` `0x1400d3210`, then ends the Scene. The leaf copies each queued TileData fade `+0x74` into current `+0x70`, marks `+0xc0=4`, and clears the Scene `+0x1b0` queued count. The [particle alpha](original-particle-effect-alpha-publication.md) and [BSP fade](geometry-and-draw-boundary.md) branches consume the TileData fade state later.
