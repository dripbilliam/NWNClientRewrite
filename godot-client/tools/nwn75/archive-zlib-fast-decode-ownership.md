## Open boundaries

The installed code proves a possible source-2 zlib fast-decode and independent output-buffer lifetime. Runtime resource selector, key table and entry, entry compression flag, XRES algorithm, zlib block/table choice, decode success, exact length, CRT buffer/OS-read choice, serviced hook subtype, and downstream render consumer remain data-dependent. The successful fast path is a CPU byte-production leaf; no GL call occurs in this decoder. The source-1 provider and Zstd/null-copy variants remain separate branches mapped only to their provider entries in the prior supplement. On failed service after `Malloc`, the local service does not immediately free `CRes+0x20`; the [failed MDL service continuation](model-resource-failed-service-ownership.md) follows conditional final-owner wrapper destruction and buffer free. Shared owners and other subtype failure paths remain open.
