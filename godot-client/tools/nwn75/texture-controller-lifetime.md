# NWN-75: original texture-controller lifetime

Pinned original `nwmain.exe` SHA-256: `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. This [ledger](texture-controller-lifetime-ledger.json) follows the controller object from the Basic texture's teardown. Controller construction, build-time `Init` and draw-time `Control` are in [build initialization](texture-controller-build-init.md) and [controller runtime](texture-controller-runtime.md). The static destructor call inherits its teardown caller's thread; no worker or graphics call is inside the controller destructors.

`CAurTextureBasic::~CAurTextureBasic` `0x1400e5210` tests controller field `+0x38` and calls the object's vtable slot zero with deleting flag 1 at `0x1400e5261`. Six constructor-backed controller vtables resolve that slot. Life `0x1400e56b0` frees state `+0x58`; Perlin `0x1400e5700` frees `+0x58/+0x60`; Arturo `0x1400e0b20` frees `+0x68/+0x70/+0x60/+0x80`; Wave `0x1400e0c80` frees `+0x58/+0x60`; CycleTID `0x1400e0b90` has no subtype image buffer; Water `0x1400e0c10` frees `+0x60/+0x70/+0x68/+0x88`. Each then calls shared `TextureController::~TextureController` `0x1400e0a00`, which frees optional source-image copy `+0x48` and two owned coefficient arrays at `+0x38/+0x28`, and conditionally invokes CRT sized delete for the controller object. This matches the first-use state fields in the build-time map. REA Basic destructor `ev_c71427cdf42d535587fc7f79836b5d824d03d1a66a2506023a6d5b1c30403157`; subtype bodies in ledger; shared destructor `ev_ad32b8ff174ce556ee323b8a30c1d6f1d45e15c1bf9d1c9e8bd5be36e6b4310c`.

The Basic destructor separately deletes GL texture IDs when `+0x50` is nonnull through `RenderInterface::DeleteTextures` `0x1400be9b0`, then releases its CPU raster according to ownership and removes itself from ordered, static/dynamic and refresh lists. Controller deletion precedes this GL deletion in the observed body; neither is unconditional for a null field. `CAurTextureBasic::Reset` `0x1400ed8d0` calls Basic `FreeImage`, resets image-construction flags, and conditionally deletes GL IDs, but shows no controller destructor or controller first-use reset. That is a separate reset/rebuild path. REA Reset `ev_3b2f7919d1c5ffb6a5cd1c62d60fd78b1c113074c7bbb1a574c2c022ac91b917`.

The exact resource lifetime is conditional on Basic texture destruction, ownership fields and subtype. External or RTTI-stripped controller tables and live object counts are unresolved. The [parser registration proof](texture-controller-parser-registration.md) establishes five `.txi`-selectable tables; the compiled Water destructor target remains conditional on an unproved producer.
