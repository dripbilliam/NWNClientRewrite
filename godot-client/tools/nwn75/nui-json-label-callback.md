# Original Nui JSON label callback

Pinned installed `nwmain.exe` SHA-256 `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`; addresses are image VAs. This closes the constructor-backed JSON `label` callback table `0x140e6e458` through its dynamic sources, CPU-only color conversion and kind-16 text path. Exact edges are in [the ledger](nui-json-label-callback-ledger.json). A second label constructor/table `0x140e6e490` has a separate callback and is not inferred from this branch.

The `label` constructor `0x14095e910` retains label text, `DynamicValue<int>` and `DynamicValue<nk_color>`, allocates a refcounted `Nui::Layout::Widget`, and calls `0x140955ec0` at `0x14095ea48`. That function creates a 0x90-byte stored callback object and writes vtable `0x140e6e458` at `0x140955eeb`. Widget render `0x1409528e0` invokes its virtual `+0x10 → 0x14095ca30`, which tail-jumps to `0x1409551b0`. At `0x1409551b0`, the callback first resolves the captured color DynamicValue from a direct pointer, optional generator or held fallback. It calls `0x140a78f20` to reorder the four color bytes. This helper is CPU-only: it has no command allocation or draw. If the reordered value is nonzero, the callback resolves the color again, resolves the captured integer value, obtains UTF-8 label text through `0x1409608e0`, and tail-jumps to `0x140a862d0`, passing explicit color. Because the color is resolved again, an installed color generator can be invoked twice on this branch. If the reordered value is zero, it resolves the integer value and label text, then tail-jumps to `0x140a86280`, which uses the current context text color. Installed generators and the original JSON value remain dynamic leaves. Both wrappers count UTF-8 bytes and call `0x140a8ff00`. Under live Nui context and active window, it calls `0x140a75460` at `0x140a8ffbb`. The latter clips/aligns text and conditionally allocates numeric kind **16** for nonempty text; the converter and glyph/GL path are established in [Nuklear command conversion](nuklear-command-conversion.md). A visible label is therefore data, style and clip dependent.
