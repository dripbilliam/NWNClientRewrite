An explicit external `SDL_DYNAMIC_API` library can replace the function table, so the built-in descendant is conditional on that selection.

`RenderInterface::SwapBuffers` `0x1400bf390` reaches `GLRender::SwapBuffers` `0x1400bb640`. It then calls `SDL_GL_SwapWindow` `0x140ab16b0` and resets GL render states afterward.
