# Original Nui tabbar option callback

Pinned installed `nwmain.exe` SHA-256 `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`; addresses are image VAs. This closes the mode-zero `SelectList` option callback `0x140e6e308` → `0x14095c7f0` through its numeric command families and selected-value publication. It is a static reachable branch, not proof that a tabbar is registered, open or drawn in a particular frame. Exact edges are in [the ledger](nui-tabbar-option-callback-ledger.json).

## Constructor and callback owner

The JSON `tabbar` constructor `0x140960260` passes mode **0** to `0x1409565c0` at `0x140960299`; JSON `options` uses `0x14095efb0` and passes mode **1**. `0x1409565c0` creates a refcounted `Nui::Layout::Widgets::SelectList` and calls `0x1409574c0` at `0x140956671`. That constructor stores the mode and a refcounted `DynamicValue<unsigned __int64>` selection source, then calls `0x14095ac30` at `0x140957587` to make option children from the supplied vector. `0x14095ac30` loops only if the vector is nonempty; in mode zero it builds a title/index function object with vtable `0x140e6e308`, wraps it in a `Widget` through `0x14095e2f0`, and appends the resulting child to the SelectList. Its mode-one callback is the separate `0x140e6e340` Licence Viewer/selectable route. This proves constructor-backed callback ownership for mode zero without conflating the modes. `Widget::Render` invokes stored function virtual `+0x10`. The pinned callback table `0x140e6e308+0x10` points to `0x14095c7f0`, a short thunk that tail-jumps at `0x14095c7fa` to `0x140955310`. That body reads the SelectList's selected-value `DynamicValue` at owner `+0x6d0`; if the direct value is absent, it asks an optional generator and otherwise uses the held fallback. It compares that value to the option's index. Only on a match does it push two selected style values before drawing; it pops them afterward. It UTF-8 encodes the option title and calls `0x140a76d50` at `0x140955462` for the selectable button. ## Numeric command and state leaves

`0x140a76d50` counts the title bytes, tail-jumps to `0x140a77240`, which requires a nonnull Nui context, active window and valid layout row, then calls button helper `0x140a62590`. The helper computes bounds/input, invokes style drawer `0x140a67be0`, and writes label text through `0x140a75460` (numeric kind **16**). Style drawer code 0 invokes filled rectangle kind **5** and outlined rectangle kind **4**; code 1 invokes image kind **17**; code 2 invokes the separate nine-slice image helper `0x140a7d2e0`, which fans out textured slices. These branches depend on input state, selected style, clipping and title content. The numeric commands enter the mapped converter `0x140a7c340` and only nonempty converted geometry reaches imported `glDrawElements`. Evidence button wrapper `ev_80e0c1ed84d3451bf9666f116864e2f9d858b6a4a7f50680c8e9b814b666cb45`, row gate `ev_19c073d357dace6d33932ecd33811a546355b740d106b4ba897e3cdf3e6347ab`, button `ev_18f3c20df7ecdd1e2a20081aa3fa6c058d8820a9ffa24dc9983ddaafb17c0449`, style `ev_77bc0530ffe06185deaa718e7416268dc432fed653c9b5d297ba18c68c45c27f`.

If the button returns a nonzero click result, `0x140955310` calls `0x14095bc50` at `0x1409554b1`. The latter validates the chosen index and, unless it is the sentinel `-1`, requires the chosen option's stored string to be nonempty. It compares the index to the previous DynamicValue. Only on a change does it assign the new value, optionally invoke its single `+0x90` listener, then iterate `+0x98..+0xa0` listener entries and invoke each stored callback `+0x10`. These callbacks are dynamic content leaves: the static path proves selection publication and listener dispatch, but not the installed listener bodies or their eventual visual/service effects.
