The [ledger](model-text-trimesh-vertex-streams-ledger.json) records all direct pool sites in `MdlNodeTriMesh::GenerateVertexData` `0x1400a7790`, REA `ev_fbbde492b84718657bf3e4217fa5472b885e06e9295223ba02066a56340ba563`. The text [postprocess](model-text-trimesh-neighbor-indices.md) calls it at `0x1400a9b49` after neighbor/index preparation when face count is positive; AnimMesh also calls the same builder after its generated-vertex step. This is model creation/refresh, not an unconditional draw.

The function returns when node face count `+0xb8` is zero. With faces, it reads 16-bit vertex count `+0x284` and the first generated `NodeVertex` from postprocess list `+0x90`. It requests and locks kind-0 pools for 12-byte positions at node `+0x280` and 12-byte normals at `+0x298`, both unconditionally inside the face branch. The first generated vertex's format bits at `+0x66` select optional streams: bit `0x10` requests four-byte packed color `+0x29c`; bit `0x20` requests 12-byte tangent `+0x2ac` and four-byte sign `+0x2b4`; bits `1`, `2`, `4`, and `8` request eight-byte UV streams `+0x288/+0x28c/+0x290/+0x294`, respectively. Each present UV stream increments node `+0x286`. Each request is followed by `LockPool` before CPU filling.

For each generated vertex, it copies position and normal components from the `NodeVertex` record into the locked pools. It conditionally copies the selected UV and tangent/sign fields; color components are scaled to 0–255, rounded and packed with opaque alpha. It then calls `UnlockPool` for all nine handle slots in a fixed order, including absent optional slots whose handles remain sentinels; the shared interface's invalid-handle behavior governs those calls. The source record's format bits come from generated vertex data, so authored mesh inputs and subtype generation control stream count. This body has nine static `RequestPool`, nine `LockPool` and nine `UnlockPool` sites, listed in the ledger; a given invocation uses only the two base streams plus its selected optional streams. `UnlockPool` reaches conditional GL buffer allocation/upload in the shared [geometry boundary](geometry-and-draw-boundary.md). The actual pool/GPU state and later Scene draw remain dynamic.

The shown builder performs CPU copies into render pools on its invoking thread and has no worker enqueue. Static analysis does not prove the OS thread, active model, vertex count, format mix, or per-frame frequency.
