# NWN-75: original GUI, overlay, and presentation branches

Status: **partial original-binary investigation**. This document covers only the installed `nwmain.exe` with SHA-256 `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. Addresses are image virtual addresses. REA/Ghidra pseudocode is an analysis of machine code, not original source. The scene geometry descendants are recorded separately in `render-single-pass.md` and `geometry-and-draw-boundary.md`. No client comparison or optimization recommendation belongs to this ticket.

The [GUI ledger](gui-presentation-ledger.json) now gives an exact machine instruction site for every direct-kind edge. The [single-site instruction evidence](gui-callsite-instruction-evidence.json) and [multi-site instruction evidence](gui-multisite-instruction-evidence.json) record REA decoder IDs. Candidate sites came from pinned PE `E8/E9` bytes in `.pdata` ranges or REA function assembly where `.pdata` did not expose a candidate; each site was independently decoded and checked against its containing procedure and direct destination. Multi-site edges use parallel `callsites` and `callsite_evidence_ids` arrays. This audit corrected a formerly collapsed GUI-to-Nui edge: `CGuiMan::UpdateAndRender` calls `0x1406c39e0` at `0x1401f76e1`, and that thunk jumps to `Nui::Window::RenderAll` `0x1406c4b20`. [The idempotent backfill tool](apply-gui-callsite-evidence.cjs) preserves ledger row formatting. Per-site data-dependent gates and runtime execution frequency remain open.

## Nuklear UI branch

The call at `0x140a71760` obtains the SDL window and drawable sizes, configures viewport/blending/shader and mapped GL vertex/index buffers, converts UI commands with `0x140a7c340`, then walks draw commands. A nonempty command binds a texture, sets `glScissor`, and calls external `glDrawElements`; it advances the index offset and restores buffer/render state at the end. The command loop and GL boundary are observed in REA `ev_6b5e1be5df3d0ec1c19e05d9f5114d2a9453a5c0bd89c9f09f1a3012d4826278`. `0x140a7c340` is a command conversion stage rather than a draw leaf; `nuklear-command-conversion.md` now records every numeric case 1–18 and its first-level geometry descendants, including the two unresolved callback targets. Converter REA `ev_ad209304a0b1e3d9ce73250523f0be0b533a57ffa37433b89d53a3d9236ce940`. `0x140a81d10` is an earlier conditional UI-context operation, REA `ev_f9cb79aada15ba0fbc419022778daec99f5222a99f1da92993e71affc3cc754b`.

All 16 computed CALL instructions in the UI draw function now have exact external GL targets in `nuklear-gl-callsites.json`: blend equation, vertex-array bind, two uniforms, vertex-attribute enabling/setup, buffer data/map/unmap. For each site, original instructions load a pointer through a pinned PE indirection cell; `gl-extension-pointers.json` matches that global to an observed `wglGetProcAddress` loader assignment. This closes **the UI draw function's targetless computed calls**, while command production/conversion and texture/program state descendants remain open. The catalog also resolves shader/uniform pointer globals used in the separate scene branch.

`0x1406c39e0` is a jump thunk to `0x1406c4b20`. The installed binary's own Tracy source-location strings and pinned RIP-relative references identify this as `Nui::Window::RenderAll`; `nui-tracy-source-locations.json` records the exact string, record, instruction and containing function for six Nui methods. `RenderAll` exits when its UI enable flag is zero; on a screen-size change it updates stored dimensions, then traverses an identifier-keyed UI registry. It removes stale entries, tests each surviving entry's active bit, calls its virtual initialization slot `+0x40` once, then calls `Nui::Window::UpdateWindow` (`0x1406c79a0`), conditionally `Nui::Window::RenderWindow` (`0x1406c5350`), and `Nui::Window::HandleOpenIntrinsics` (`0x1406c2f40`). `UpdateWindow` checks the named UI window's visibility/context and ends with an entry virtual `+0x58` call. `RenderWindow` handles screen positioning, GUI scale and other context work; `HandleOpenIntrinsics` is an entry virtual `+0x8` wrapper. Separate source-location records identify `Nui::Window::Render` (`0x1406c44e0`) and `HandleCloseIntrinsics` (`0x1406c28c0`).
