This index is a route to the branch evidence, not a claim that every render-affecting path has been discovered. The [main tree's scope frontier](original-render-tree.md#scope-frontier) remains the human-readable list of unfinished families. Runtime measurements would corroborate active routes and thread identity; static graph edges alone do not establish those facts.

The [texture/header source audit](resource-disconnected-source-audit-3.md) classifies one more exported alternate root and corrects TTF callsite and PLT vtable-slot source aliases in their existing ledgers.
The [TTF resource source audit](ttf-resource-disconnected-source-audit.md) resolves the stack-helper destructor callsite alias and retains the separately exported CResTTF helper setter as an alternate root.

Run `node tools/nwn75/audit-ledger-reachability.cjs` from the client repository to inspect how the current ledgers connect to the pinned PE entry. Additional roots can be passed as arguments, for example `0x1400451c0` for `UpdateScreen` and `0x140233980` for movie presentation. Disconnected sources can be alternate roots, omitted connector records or unresolved computed dispatch; the output is an audit queue, not proof that code is dead or a completion percentage.

Run `node tools/nwn75/validate-map.cjs` to check ledger JSON, evidence-ID shapes, identical records and local Markdown links. Run `node tools/nwn75/audit-direct-callsite-bytes.cjs <pinned nwmain.exe>` to compare literal E8/E9 rel32 and EB short-jump ledger sites with the original PE. The latter only verifies the encoded target of those instruction forms; computed dispatch, branch conditions and runtime execution require separate evidence.

Run `node tools/nwn75/audit-callsite-coverage.cjs <pinned nwmain.exe> [--full]` to identify direct-kind ledger records without an exact machine-readable instruction site. `explicitSite` counts records; `explicitSiteInstances` counts each address, including `callsites` arrays. The byte auditor checks every literal address in those arrays, while `validate-map.cjs` checks any parallel `callsite_evidence_ids`. The optional full report lists pinned E8/E9 byte candidates within each source `.pdata` range; an analyst must confirm instruction ownership and gates before recording a candidate. This is an open documentation-completeness audit, not a function or runtime reachability proof. An edge can be correct in prose while lacking a structured site.

`inspect-pe-exports.cjs` resolves named PE export entries for ambiguous original addresses. Its use in the [presentation census](presentation-entry-census.md) identifies `RestoreFrontBuffer` as an exported optional entry, while leaving external call frequency unknown.
