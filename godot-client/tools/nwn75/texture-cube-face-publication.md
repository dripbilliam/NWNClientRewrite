# NWN-75: original cube-texture face preparation and publication

Pinned original `nwmain.exe` SHA-256: `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. This [ledger](texture-cube-face-publication-ledger.json) follows the six-face CPU preparation below `GLRender::CreateCubeTexture` `0x1400aeff0` and rejoins the imported GL publication already mapped in [texture publication](texture-publication-per-frame.md). This call inherits its texture-build caller's thread; no separate worker appears in these three functions.

The cube routine resets the active texture stage if needed, applies texture parameters, and loops six GL cube-face targets beginning at `0x8515`. It treats the source image as six stacked faces, using fixed source-face permutation `[1,0,2,3,4,5]`. For each face it obtains Basic width, height, BPP, image and tile/grid getters, computes face dimensions, and may call `ImageGetSubImage` `0x140072010` at `0x1400af1aa` unless both tile tests equal one. It then calls `ImageQuarterRotated` `0x1400ebc10` at `0x1400af1f2` with fixed rotation codes `[1,3,0,2,2,0]`. The rotation helper allocates a full face-sized byte buffer at `0x1400ebc55` and copies BPP-sized samples to quarter-turn coordinates at `0x1400ebd1c`; its recovered body allocates even for code zero. The subimage helper allocates `BPP*tileWidth*tileHeight` bytes at `0x140072045` and copies each selected pixel at `0x1400720ca`. REA cube `ev_1f9ddbaf37d8d5b350a93d0e301578f18f700a525062108567526dd3e25174a8`, subimage `ev_2d471a332db55f3f88328393444045d2e775fcd39598a1ce502f83f9afc3abdc`, rotation `ev_608f51112a320d45cf68202cd2e2e8e676b009c8415b19bc2392f9a03fc6c940`.

For each prepared face, update mode calls imported `glTexSubImage2D` at `0x1400af25f`; define mode calls `glTexImage2D` at `0x1400af277`. The routine then frees the rotated buffer when distinct from the selected subimage pointer at `0x1400af285`, and frees the subimage buffer when distinct from the original face pointer at `0x1400af292`. Optional mipmap generation follows the six-face loop at `0x1400af2bd`. The exact Basic getter and GL callsites are also in [cube indirect callsites](texture-cube-indirect-callsites.json). These are conditional texture-build operations, not unconditional per-frame draw work.

Open selectors include actual cube asset use, tiled versus untiled source, dimensions/format, update versus define mode, texture parameters, GL success and live build frequency. The GL driver remains an external boundary.
