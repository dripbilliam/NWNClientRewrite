# NWN-75: shader SHD resource service handoff

Pinned installed `nwmain.exe` SHA-256 `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. This connects the existing [shader source and compile path](shader-program-branch.md) to the concrete type-`0x815` `CResSHD` resource object and its serviced byte buffer. It is conditional program construction or reload work; static evidence does not make it an ordinary per-frame shader-file read.

The shader source loader `FUN_1400b46d0` calls `AurResGet(name,".shd",&length,true)` at `0x1400b4875`, copies returned bytes into a null-terminated CPU buffer, releases the resource at `0x1400b48c3`, and recursively loads any admitted `#include` source. A missing resource, zero byte count or missing include prevents a usable source. The original shader-program note follows its later generated header, GL compile, link and draw-time program selection. Named `AurResGet` calls the installed `CAuroraInterface::GetResource 0x1400f63d0`; its `true` flag returns null on a callback miss without a local-file fallback. Evidence: `ev_a8bdacbcc98104228a9ed23b02596981d91401d3fe83656530b2c43bdf95026e`, `ev_4b5c726e5bb7814cf8170b2a43139e52bda197f37c013815f19c2b563595f437`.

`GetResource` strips a leading dot and uppercases the extension, matching `SHD` bytes `53 48 44 00` at `0x140d92680`. It constructs `CAuroraShader 0x1400f8710` at `0x1400f6c83` and calls `LoadShader` at `0x1400f6c97`. The wrapper constructor seeks `CExoResMan::GetResObject` for type `0x815` at `0x1400f881b`; on a miss it constructs `CResSHD 0x1400faf40` at `0x1400f883d` and registers the object at `0x1400f885d`. `CResSHD` installs vtable `0x140d92bc0`: `+0x18=OnResourceFreed 0x1400fb000`, `+0x20=OnResourceServiced 0x1400fb010`. The four generic storage service callsites may select this hook only for a constructed SHD object after their own successful read/copy gates. `LoadShader 0x1400f8af0` calls `CRes::Demand` at `0x1400f8afd`, returns zero on failure, and on success obtains the SHD data pointer, writes type `0x815` and its wrapper owner into the bytes preceding that pointer, and sets loaded state `+0x28`. `OnResourceServiced` requires nonnull `CRes+0x20`; first service copies CRes byte count `+0x30` to SHD `+0x64`, data pointer to `+0x68`, and sets serviced flag `+0x60`. On a successful load `GetResource` reads SHD size and pointer at `0x1400f6ca7/0x1400f6cb3`, returning them to `AurResGet`. The service hook does not compile a shader or call GL. `AurResFree` calls the installed `ReleaseResource` callback for callback-backed data. Its type-`0x815` branch calls `CAuroraShader::UnloadShader` at `0x1400f8c90`, which conditionally calls `CRes::Release` at `0x1400f8ca3` and clears loaded state before deleting the wrapper. `CResSHD::OnResourceFreed` later clears its serviced pointer fields when eligible manager reclamation invokes it. Resource source/cache selection, actual authored shader names and GL compile success remain dynamic boundaries.
