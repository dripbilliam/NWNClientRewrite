All 24 body identities were inspected in the original REA session. Each deallocation body has one call to `0x140c10360`; original bytes at that address jump via `0x140c1148c` to CRT free helper `0x140c4f024`. Its full native analysis exceeds the provider's response budget, so this document does not assert a later OS boundary. Each scope-end body calls `Instrumentation::EndScope` `0x14030ed00`, then `FrameTrace::pop_scope` `0x140312b60`. On an admitted active scope, pop_scope reads `CExoTimers::GetMicrosecondTimer` `0x14016dd30`, records elapsed time and may call `FrameTrace::advance_frame` `0x1403109e0`. The timer's zero-mode path calls `CExoTimersInternal::GetMicrosecondTimer` `0x14016e0f0`: it reads cached time when `g_bUseThreadedTimers` is set, otherwise calls `GetMicrosecondTimerReal` `0x14016e110`, which reaches `KERNEL32::QueryPerformanceCounter` or `GetTickCount` according to timer mode. `advance_frame` can call the same timer and two further internal helpers `0x140bea164`/`0x140be7780`; those descendants remain open. This branch does not issue GL calls in the observed bodies.
