# Text MdlNode base fields and parent attachment

Pinned original `nwmain.exe` SHA-256: `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. [Ledger](model-text-base-node-fields-ledger.json) records the shared base parser reached by the [text TriMesh dispatcher](model-text-trimesh-fields.md) and other typed node parsers. `MdlNode::InternalParseField` `0x140099650`: REA `ev_2b4f1308fcbcb36387fa374334c9e4bb942e8f471c20d33b171c3fda14487606`.

The base parser extracts the first word into a 0x400-byte shared buffer and checks its bound. It compares field names case-insensitively except for the `parent` prefix, which uses `strncmp` on the first six line bytes. `position`, `orientation`, and `scale` each accept a direct value via `AddGenericControllerSingle` `0x140098790`, a `key` form via `AddGenericController` `0x140098570`, and a `bezierkey` form via `AddBezierController` `0x140098340`. They write node controller/value lists `+0x78/+0x88` with destination offsets `0x10`, `0x1c`, and `0x2c`, respectively. Their resource and CPU-array leaves are in [controller builders](model-text-controller-builders.md); later pose interpolation and Part control are in the [non-emitter animation](original-scene-animation-nonemitter.md) branch. `inheritcolor` parses an integer into node `+0x30`. `wirecolor` scans three floats into a local temporary in this body; the shown parser does not store or forward that temporary. A token bound violation calls `__report_rangecheckfailure` `0x140c11104`.

For `parent NULL` (case-insensitive value), the parser clears node parent `+0x60` and stores this node as its owning MaxTree's root `+0x50`. For a named parent, it starts at that root, checks its name and searches its children recursively with `FindMdlNode` `0x140098c30` (REA `ev_a00e9dd57f2b38e9b7d934e3ec556c1545c2514110a4cf92f8c61df13d1ecc68`). That helper compares names case-insensitively and walks child pointer array `+0x68` with count `+0x70`, returning the first match or null. The parser stores the selected parent at node `+0x60`, grows the parent's eight-byte child-pointer array with `_realloc_base` when needed, appends this node and increments count. These are CPU tree ownership operations; no GL or render-pool call occurs in either body. The decompiled named-parent path dereferences the returned parent after the search, so missing-name behavior cannot be treated as a normal no-op without additional input/runtime evidence.

Static code does not establish active authored controllers, parent topology or invoking OS thread. The later recursive instance creation and draw are conditional descendants mapped in [model instance](model-instance-branch.md) and [Scene geometry](geometry-and-draw-boundary.md).
