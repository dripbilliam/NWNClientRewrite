## WebM movie resource and descriptor gates

`0x140a93db0` first invokes resource refresh `0x140a94350`. If resource `+0x48` holds a `CExoMoviePlayer*`, it calls wrapper UpdateMovie `0x140232250`, then obtains its texture and writes the `nk_image`-style descriptor at resource `+0x60`. When resource `+0x0` is zero, it returns that descriptor if the texture/frame-count state is usable; multiple frames advance by a microsecond timer and frame-duration list. If the resource is absent or invalid it instead returns lazily prepared `gui_notfound` or `gui_error` descriptors; nonzero `+0x0` returns `gui_loading`. These are CPU/resource selections before the caller's numeric image command, not direct draws (REA helper `ev_5fec165647d49f5bcc27530854e440a12aee98ce0f33a64131a00d96d0687673`, fallback `ev_130bfdcb1054d822e0e5dfc77599f5e155c10d41831a99978a7c2dabfd404d43`).

In `0x140a94350`, a resource stream whose first little-endian word is `0xa3df451a` (EBML `1a 45 df a3` bytes) enters the WebM branch. It constructs a `DataViewStream`, then calls the shared-stream `CExoMoviePlayer` constructor `0x140231fb0` with boolean `false`, stores the wrapper at resource `+0x48`, and, if loaded, records dimensions/texture, enables looping and disables audio decode. Otherwise it records `webm file failed to load` (REA `ev_35f7701d91c3e56ec92c348816d7f44764547efbbe4804084efac5a1b1747150`, wrapper `ev_bdd938704a264b2db2cebd3001633010e9fafe4f122ab59d9a7e4fedcee5d9da`). The wrapper forwards false through `CExoMoviePlayerInternal` constructor `0x140232d00` to `Initialize` `0x140233100`, which writes the flag to internal byte `+0x0` (REA `ev_00a209fd19c56946dfc5633474921e6bfa8163e33dd218690c4861ccc6ca3b6e`, `ev_75e671351d5655da928aceff74dddce28c8c8c05141b8e9f561df15637769919`). Under this constructor path, UpdateMovie can decode/upload the texture but its `ShowFrame` direct quad is gated off. The callers display the texture via their Nui image commands.

The direct-reference census of `CExoMoviePlayerInternal::Initialize` shows only the two constructors `0x140232620` and `0x140232d00` as callers (REA `ev_cf588adfa3c59667db293b1dce42c8598924efbb225fa2b40a783549870813a2`). A bounded body inspection of all seventeen `CExoMoviePlayerInternal::` named constructor/method/destructor bodies found the only explicit assignment to `*this` in `Initialize`; `UpdateMovie` reads it as a gate. This does **not** prove no unnamed or indirect writer can modify the flag after construction. The known JSON MoviePlayer member and the generic WebM image-resource path both pass false, so neither constructor-backed GUI route invokes direct `ShowFrame` unless later code changes that byte.
