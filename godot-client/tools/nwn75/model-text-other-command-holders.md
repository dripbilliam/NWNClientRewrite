# NWN-75: six additional text-MDL command holders

Scope: installed `nwmain.exe` SHA-256 `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. This continues the [text command registration](model-text-command-registration.md) and [name-based model parser](model-name-parser-tree.md). It covers six other tokens accepted by the `FindModel` whitelist, their CRT constructor entries, exact registry holder type, and the state they publish. It does not imply every model contains these commands or that model parsing occurs each frame.

## Startup and callback dispatch

The CRT `_initterm` range `[0x140d7d790,0x140d7fea8)` contains pointer entries for `newanim` at `0x140d7da88 -> 0x1400152a0`, `donemodel` at `0x140d7da98 -> 0x140015240`, `classification` at `0x140d7daa8 -> 0x140015180`, `ignorefog` at `0x140d7dab0 -> 0x140015270`, `setsupermodel` at `0x140d7dab8 -> 0x140015330`, and `setanimationscale` at `0x140d7dac0 -> 0x140015300`. Original pointer bytes and registration-function assembly establish each pair. The `newmodel` and `beginmodelgeom` entries in between are covered in the linked registration note. The four `void(char*)` handlers (`classification`, `donemodel`, `ignorefog`, `newanim`) pass their literal names and function addresses to `ConsoleFunc::ConsoleFunc` `0x14005d040`, which installs the existing vtable `0x140d83d48`, with `+8=0x14005e670` (`Engage`). The two `char const*(char*)` handlers (`setsupermodel`, `setanimationscale`) instead call constructor `0x14005cfd0`; it stores a second holder vtable `0x140d83e38`, whose `+8=0x14005e5f0`. That `Engage` invokes its stored pointer at `0x14005e5fb`, then copies the returned string, or the empty fallback, into global `returnvalue`. `FuncInterp` uses its original whitelist and exact-name `FindConCallBack` before either computed holder call at `0x14005f68c`. Each named target below therefore requires its own registered holder and a matching parsed token. ## Model state and typed descendants

| Token and target | Selected original effect |
| --- | --- |
| `classification` `0x1400a11b0` | Case-insensitive `tile`, `character`, `effect`/`effects`, or `door` writes a distinct byte to `currentmodel+0x92`; unmatched text leaves it unchanged. |
| `donemodel` `0x1400a15c0` | Empty handler body; the surrounding `ImportMaxTree`/interpreter terminator handling is separate. |
| `ignorefog` `0x1400a1630` | Parses an integer; only value 1 writes zero to `currentmodel+0x93`. |
| `newanim` `0x1400a17f0` | Parses two words, constructs a `0xe8` Animation, grows the model animation pointer array at `+0x98`/count `+0xa0` if needed, appends it, then calls `ImportMaxTree`, `Animation::PostProcess` and `MaxTree::SynchronizeTree`. These typed descendants connect to later model animation/Part state. |
| `setanimationscale` `0x1400a1970` | Parses a float with initial value 1 and writes `currentmodel+0xcc`; returns `done` to the return-value holder. |
| `setsupermodel` `0x1400a19c0` | Drops the old supermodel reference if present, copies the parsed supermodel name to `currentmodel+0xd0`, recursively calls `FindModel`, stores the result at `+0xa8`, adds its reference if nonnull, and returns `done`. |

The whitelist also accepts the spelling `filedependancy` (literal `0x140d8a310`), but a command-holder constructor and target for that token are not established by this branch. The six proved handlers have runtime data-dependent arguments; this map records the static target and field effects only.
