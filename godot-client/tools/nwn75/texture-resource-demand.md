## Lower I/O boundaries

The directory service's `CExoFile::Read` `0x140166ca0` forwards to `CExoFileInternal::Read` `0x140167c60`, which reaches CRT `fread` at `0x140167cdb`. The CRT chain is `fread` → `fread_s` → `_fread_nolock_s` → `_read_nolock` (directly or via `_read` after stdio refill) → imported `KERNEL32.DLL::ReadFile` at `0x140ca7a53`. That imported call is the observed OS file I/O boundary for this source kind. The buffered refill branch passes through `__acrt_stdio_refill_and_read_narrow_nolock` and `_read` before the same `_read_nolock` call. Console-specific `ReadConsoleW` is a separate CRT branch.
