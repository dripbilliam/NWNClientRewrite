This follows the active-bin sort in [scene-grass-wind-sort-continuation.md](scene-grass-wind-sort-continuation.md). It maps the indirect comparator calls and sort helpers, not a measured per-frame cost. `Scene::DoBinBucket` passes its farther-first comparator `0x1400c5980` to `_Sort_unchecked<CAurTriangleBin*>` at `0x1400c77a3`, only under `g_bSortGrass`. The callee retains that passed pointer in `R15` and passes it through `R9` to partition, recursion, and heap. Partition and median retain it in `RBP`; heap reads it from the fifth stack argument into `R12`. Thus the indirect calls below target the same comparator for this specific caller, although the generic sort functions can be used with another comparator elsewhere.
