Scope: installed `nwmain.exe` SHA-256 `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. This closes one concrete caller and constant name for [Scene highlight texture publication](scene-highlight-texture-and-stream.md). The prior note covers texture binding, outline stream and conditional GL submission. Resource-provider/texture upload internals and other possible callers are separate branches. No runtime highlight frequency or frame cost is inferred.

The large client-area setup body `0x1407dba70` accesses its Scene pointer at area `+0x248`, reads that Scene's vtable and calls slot `+0x128` at **`0x1407de7d4`** with string address `0x140e45e90`. The original Scene table `0x140d8dd30` has `+0x128=Scene::SetHighlightGobTexture` `0x1400d3420`, so this is a concrete area-setup producer of the highlight texture name. Evidence: setter above, Scene destructor `ev_9e802bd7b0e6aca27fe4d398c3eccb7dfe399651ab19baeeac749b7e2a851c2a`, [highlight consumer](scene-highlight-texture-and-stream.md).
