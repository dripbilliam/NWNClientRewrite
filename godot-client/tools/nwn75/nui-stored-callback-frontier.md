# NWN-75 original Nui stored Widget callbacks

Scope: installed `nwmain.exe`, SHA-256 `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. Addresses are image VAs. This is a static callback-target census and selected descendant closure, not a runtime widget list.

## Dispatch and callback-table census

The four `Nui::Layout` content `+0x20` families are `0x140950d90` (group), `0x140951260` (layout/span/select list), `0x1409528e0` (Widget/StatefulWidget) and `0x14095b1a0` (MoviePlayer); their exact eight RTTI-backed vtables and two `+0x28` child families are in [nui-layout-rtti-vtables.json](nui-layout-rtti-vtables.json). Group `0x140950d90` conditionally calls a child's `+0x28` during geometry recomputation, while `0x140951260` dispatches each stored child's `+0x20` during render. The Widget target `0x1409528e0` loads its function object from `widget+0x6f8` and invokes that object's virtual `+0x10`, or fails if absent. Thus the content class alone does not identify the command producer. REA `ev_8349061de9d3bbf73c9f3aa261147274cb6ad791445126e81f2fdeef157ab41e`, retained layout body `ev_fad75cefad3cd5f81b65559a485d8c263e4b4dddc0ad801c7d6dbbc2cf0195da`, Widget dispatcher `ev_36c2885cff10e09a952779a2ab49478bab1ecb41b5421104f5595660b713de86`.

The [stored callback ledger](nui-widget-callback-vtables.json) scans pinned `.rdata` MSVC Complete Object Locators and exact `std::_Func_impl_no_alloc` type signatures accepting `Nui::Layout::Widget` or `StatefulWidget` with a Nuklear context. It finds **31 vtables with 31 distinct `+0x10` callback targets**. Their executable RIP-relative code-reference census has 93 references, two to four per table. Each ledger row gives the original callback-slot bytes and REA target evidence, all candidate code-reference sites and the first-level direct callees. This exhausts that RTTI signature pattern in the shipped `.rdata`; it does not prove that every candidate is installed in a live Widget. Constructor paths for JSON types and several programmatic windows are separately proven in [json-widget-callbacks.md](json-widget-callbacks.md) and [nui-content-continuation.md](nui-content-continuation.md).

## Unresolved callback edges

* [Nui callback descendants](nui-callback-descendants.md) binds `0x140e4b650` to `Nui::ConfigWindow::0x1408318c0`, the recursive TreeNode table `0x140e6e650` to `0x1409555b0`, and group Widget `0x140e3b328` to conditional group/clip command leaves. Their dynamic child content, config values and runtime visibility remain open.
* Other ledger callbacks' first-level direct callees are exact, but many stored JSON values, programmatic window content trees, event functions and style-dependent downstream helpers still require individual branch closure. A RIP-relative reference to a function table may be a constructor, clone or destructor site; the 93 references are candidates until pointer flow is checked. Runtime registered/visible instances are not inferred.
