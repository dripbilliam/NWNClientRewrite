At `0x1400dff06` it requests a `0x40`-kind pool of `8 × generated_vertex_count` bytes, stored at node `+0x2dc`, then locks it at `0x1400dff18`. This is four 16-bit indices per vertex. At `0x1400dff43` it requests another `0x40`-kind pool of `16 × generated_vertex_count` bytes at node `+0x2d8`, then locks it at `0x1400dff55`; this is four 32-bit float weights per vertex. The paired CPU fill reads the deduplicated 72-byte `SkinVertexWeight` array at `+0x2c8`, initializes each index and weight slot to `-1`, then copies an authored weight. Zero weight leaves the index at `-1` and the weight at zero. For positive weights it resolves the bone index through the remap array and writes a compact index to the index stream; an unresolved bone can leave the pair at `-1`. A previously unseen valid bone index receives the next compact 16-bit value; the reverse relation is also written into the node's compact bone-index storage. The decompiled loop is heavily unrolled, so the four-stream interpretation follows the pool byte sizes, strides and field offsets as well as the loop body.

It unlocks the weight stream at `0x1400e031c` and the index stream at `0x1400e032b`, releases the node's deduplicated weight array, invokes shared tangent-basis calculation `0x1400e0351`, and calls the installed `+0xa8` temporary-array cleanup at `0x1400e0360`. This branch ends at pool ownership and the existing shared GL continuation; driver work, active data, invalid bone references and malformed-resource outcomes remain dynamic.
