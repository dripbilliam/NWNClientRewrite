# NWN-75: texture TXI resource service and parser handoff

This closes the `.txi` path between an admitted Basic texture initialization, the generic Aurora resource callback, the `CResTXI` serviced buffer, and field parsing. It describes conditional static behavior, not the number of TXI files loaded in a live scene.
