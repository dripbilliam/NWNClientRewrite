## Selected lights to shader state

The selected arrays feed the per-pass `LightManager::EnableLights`/`EnableLightsDynamicOnly` routes described in [lighting state](lighting-state-branch.md). Both dispatch through LightManager virtual `+0x60=ControlLightsFade` `0x14007ddb0`. That function reconciles selected and active lists, changes each light's fade, stages area light colors, calls `SetHeadLightProperties` when enabled, calls `SetLightGL` `0x140080c10` for admitted slots, and disables the remaining slots. Its 26 exact direct callsites replace earlier pair-only ledger records. `SetLightGL` has 24 exact direct callsites: slot `-1` stages area ambient/diffuse; numbered slots stage six properties through `RenderInterface::SetLightProperties`, then enable or disable based on the global shader mode and view test. REA `ControlLightsFade` `ev_5e1b986448e594166d85457c16ea9f02afa177597f80cbc69033e97697bb2c09`, `SetLightGL` `ev_00ada17410388827f13bcbc8e5390b55372fa96378292c72c6118a7edd7d7772`.

The five RenderInterface light setters are tail jumps to `GLRender::SetLightProperties` `0x1400b7320`, `EnableLight` `0x1400b3330`, `DisableLight` `0x1400b0550`, `SetAreaAmbientLight` `0x1400b67e0`, and `SetAreaDiffuseLight` `0x1400b6840`. They compare against cached light values or enabled bytes and advance `DAT_1413d26fc` only on change. The first three call `LightManager::GetMaxLights` `0x14007f640`, which caps configured slots at 128; the area setters have no callees. None calls GL immediately. Full REA GL bodies respectively `ev_981b5adf1b202b1dd8333231420a2b0b8e23cc0a1a1bd4a71495b1eb1411cfc0`, `ev_07f03b4d18d1739449af17debaf5726476523658da67fbef297b4e80cd1a4a88`, `ev_b6371e3d2f20d92d2281c93f4227ad21fe08e971fca4b68c619c382bf9513823`, `ev_f96808a873d5f6c85eb59e654ecc30929068afef707699983cbab008a80f670a`, `ev_11c2793bb70c1d8a68bc107e560edeb7d1c6d718e6b3d641c46929dcf1891ea5`.

`GLRender::SetProgram` later calls `GLRender::SetUniforms` `0x1400b8380`. That function publishes the light arrays when the selected program's light generation differs from `DAT_1413d26fc` or its view-matrix generation changed, subject to valid uniform locations. Its packed light output reaches loader-identified `glUniform1i`, `glUniform4fv` and `glUniform1fv`; area color/direction uniforms follow. Exact GL sites and gates are in [shader uniform dirty gates](shader-uniform-dirty-gates.md) and [the GL callsite catalog](shader-uniform-gl-callsites.json), retained SetUniforms REA `ev_1a4116233c92836c24653152acff91f84c48e7899cc3e2c69a0d2729deec3431`. Thus this branch joins the external API boundary through a changed-state or changed-view gate. This static map does not measure how often those gates fire.

The light-selection path supplies later per-Part lighting and shadow buckets. The lower vector/Gob transform helpers and other shader inputs remain explicit open descendants; the sort's static helper/callback target family is bounded, while its runtime comparison count depends on selected-list size and ordering.
