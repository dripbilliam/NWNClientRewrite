# Original Nui licence viewer route

This branch follows the registered `Nui::LicenceViewer` from its Config-window button callback to one concrete selectable text draw. It uses the installed original binary SHA-256 `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. The [ledger](nui-licence-viewer-ledger.json) pins the instruction sites. Construction and active-frame visibility remain separate facts.

This is input/action gated and also requires the Config window and button to be active. The constructor names the window, sets its dimensions to 500×400, and calls `CExoBase::GetDirectoryList` for `DOCINSTALL:licences/` at `0x1408293f8`. It iterates returned entries. For each entry it opens `DOCINSTALL:licences/<entry>` through `CExoFile::CExoFile` at `0x14082951d`; only `FileOpened != 0` and `GetSize > 0` enter `CExoFile::Read` at `0x1408295b4`. The directory listing and file read are CPU/file I/O leaves here; exact installed entries and lower `CExoFile` backend choice are data-dependent. ## Conditional GUI draw leaf

If the Licence Viewer survives the weak registry, global/UI mask, open and window `+0x8` gates, `Nui::Window::RenderAll` reaches `RenderWindow` and its base `Nui::Window::Render` target `0x1406c44e0`. With nonnull installed content at `+0x108`, the content virtual `+0x20` descends the `SingleGroup` and `SelectList` child family. `FUN_14095ac30`, called by SelectList construction through `FUN_1409574c0`, creates one option Widget per title when the vector is nonempty. The Licence Viewer passes mode 1, which installs callback vtable `0x140e6e340`; its `+0x10` target is `FUN_14095cbb0` at `0x140e6e350`. That callback converts each stored title to UTF-8 and calls `FUN_140a881a0` at `0x14095cc42`, which measures the string then reaches `FUN_140a881d0 → FUN_140a67050` under valid Nui context/window/row gates. The selectable helper's style/clip path can emit kind-16 text through `FUN_140a75460`; Nui conversion and draw reach imported `OPENGL32.DLL::glDrawElements` only if the command and geometry are nonempty. REA option builder `ev_bd502a0e0b79b85c876981e532babe5cc055ee211a29db7d96ddb63bf8d081f2`, callback table bytes `ev_f79e519abc106d796b7f854ba51abd8fd361a34b08b0a912652bd3317f1e0aa1`, callback `ev_b6ca65777baa171e61278bc6b62265f90dbb05be0ef4a9475f3c6fba705906a8`, selectable wrappers `ev_d4f1fa9ae4ae5980993d5a6ef83cfbb431b6c985c9e5d6990e26a20fcc0541db`, `ev_e62e41fad7464edc8826d673223e51d484568320103184d06a2c9545432dd35a`; common kind-16 and GL leaves are documented in [Nui registered command reachability](nui-registered-command-reachability.md).

The selected licence body uses a separate label child constructed by `FUN_140832810`; its glyph/font conversion follows the already mapped Widget text family only when a valid index has been selected and that child is visible. The full set of optional buttons and style commands in this constructor is outside this bounded title/content route. The GUI construction, selection callback and draw inherit their caller thread. No worker launch is observed on these edges; file-I/O implementation internals and frame-specific OS thread IDs remain open.

**Open edges:** actual Config button press, installed licence directory contents and file source, whether the Licence Viewer remains registered/open/mask-visible, selected index and child visibility, font/clip output and final draw count.
