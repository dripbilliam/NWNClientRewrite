# NWN-75 authored texture sampler publication

Pinned original `nwmain.exe` SHA-256 `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. This follows a Basic texture's authored clamp/filter/mipmap fields into the shared 2D/cube upload parameter setter. The resource lookup and broader image upload are mapped in [controller parser registration](texture-controller-parser-registration.md), [texture publication](texture-publication-per-frame.md), and [2D maximum-size upload](texture-two-d-max-size-upload.md). This note covers the parameter work on an admitted upload, not per-frame frequency.

`CAurTextureBasic::Init` `0x1400ebe40` reads a named `.txi` resource when present and calls `CAurTextureBasic::ParseField` `0x1400ecf20` at `0x1400ebfdc` for each line. The parser recognizes `mipmap` into Basic `+0xe4`, `filter` into `+0xe5`, and `clamp` into the short at `+0xc8`. The Basic constructor `0x1400e4d60` initializes both mipmap and filter bytes to one and the clamp short to zero before any authored overrides. The same parser also accepts alternate texture-message/console inputs, whose admission is separate from `.txi` lookup. The getter wrappers `GetMipMap` `0x1400eba00`, `GetFilter` `0x1400eb820`, and `GetClamp` `0x1400eb700` resolve a referenced Basic texture and return those fields, or false/zero for a missing Basic. `GLRender::CreateTexture` `0x1400af440` calls `GLRender::SetTextureParameters` `0x1400b8100` at `0x1400af5a7` after reading the Basic clamp/filter/mipmap getters. `GLRender::CreateCubeTexture` `0x1400aeff0` calls the same setter at `0x1400af06f` for a cube target. The setter maps clamp bits 0, 1 and, for cube only, 2 to wrap S/T/R: set bits choose `GL_CLAMP_TO_EDGE=0x812f`, clear bits `GL_REPEAT=0x2901`. It issues imported `glTexParameteri` for S at `0x1400b8152`, T at `0x1400b816c`, optional cube R at `0x1400b818b`, magnification at `0x1400b81ac`, and minification at `0x1400b81d3`. Magnification chooses nearest `0x2600` or linear `0x2601` by filter. Minification chooses nearest `0x2600` with mipmap off, or `0x2700`/`0x2703` with mipmap on and filter off/on. These calls occur when the upload calls this setter; no parameter-value cache gate appears in its body. For anisotropy, the setter writes value `1.0` unless both mipmap and filter are enabled. With both enabled, a cached maximum of `-1.0` invokes imported `glGetFloatv(GL_MAX_TEXTURE_MAX_ANISOTROPY_EXT=0x84ff)` at `0x1400b8202` once for this global cache, then uses the lesser of the configured `g_nTexAnisoFilterLevel` and reported maximum. The setter tail-jumps to imported `glTexParameterf` at `0x1400b8252` with `GL_TEXTURE_MAX_ANISOTROPY_EXT=0x84fe` in either case. Separately, `AurTextureMakeCurrent` `0x1400e8be0` compares the configured level to its prior value; only a change calls `AurTextureRefreshAll` at `0x1400e8ccf`, whereas an unchanged value with pending textures calls `AurTextureBuildAndStoreAll` at `0x1400e8cdf`. Actual `.txi` rows, global level, GL maximum and upload admission remain dynamic.
