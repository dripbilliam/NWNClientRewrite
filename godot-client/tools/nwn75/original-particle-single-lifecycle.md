# Original Single emitter source and particle lifetime

Pinned original `nwmain.exe` SHA-256: `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. This expands the Single branch of [Explosion and Single](original-particle-explosion-single.md). Addresses are original-binary static sites, not evidence that a particular installed effect executes them.

## Source selection and controller publication

`MdlNodeEmitter::InternalCreateInstance` `0x1400621f0` compares the source update string `+0xb8` against `Single` at `0x1400622d3..0x1400622f5`. A match allocates a `0x248`-byte `PartEmitter`, calls its constructor at `0x140062314`, installs the Single vtable at `0x140062320`, stores its owner Gob at `+0x50` and invokes virtual `+0xf8=Initialize` at `0x14006237c`. The Part base constructor stores the source pointer in instance `+0x8` at `0x140087d91`. An unrecognized update string instead selects the Lightning arm; the comparison itself is the Single subtype gate. Factory evidence `ev_e9806c355853e25ce0b29fba8bd9035e6d113563e1d021a4effee3441c5add89`, Part base `ev_7dc3cd40daa2cef1a735fdc3efd55f2228e4d94a2a51d2249fa35639286277d4`.

The source constructor clears the eight bytes at `MdlNodeEmitter+0x168` at `0x1400875c1`, including the `loop` integer at `+0x16c`. Text parsing recognizes `loop` and calls integer `Parse` into `+0x16c` at `0x14009b008`; compiled node-type-5 reconstruction copies serialized `+0x13c` into the same field at `0x14007b227`. `lifeExp`, `lifeExpkey`, and `lifeExpbezierkey` controller entries target instance `+0xac` at parser sites `0x14009c9cb/0x14009ca09/0x14009ca45`; `particleRot` variants target `+0xbc` at `0x14009ccfb/0x14009cd39/0x14009cd75`. The shared `birthrate` variants target instance `+0x74` at `0x14009b677/0x14009b6b5/0x14009b6f3`. `MdlNodeEmitter::InternalControl` calls base controller sampling at `0x14005244c` when the emitter Part is admitted, allowing active authored keys to publish these fields. `PartEmitter::PartEmitter` zeros `+0x74`, `+0xac`, and `+0xbc` at `0x14006053e/0x14006055e/0x14006056c`. ## Update: one live particle, one of three paths

`Scene::DoEmitterBucket` calls `PartEmitter::AnimateParticles` at `0x1400c7c94` only if Scene animation or owner force-animation admits it. After owner/fade checks, pose derivation and delta clamping to `0.5`, virtual `+0x100` at `0x1400615bf` selects `SingleEmitter::Update` `0x140065cd0` for this constructor-backed vtable. The update converts instance float `birthrate +0x74` to a signed integer at `0x140065cf3`, then tests **nonzero**, not positive, at `0x140065cf8..0x140065cfa`. A positive fractional value below one therefore takes the disabled branch; a negative value with nonzero integer conversion takes the enabled branch. Evidence Scene `ev_b4881207528882fb849869474dcd3a31c18cf9f00dad89280e126d85fcdd7ed3`, animation `ev_94298fdbef50a777edca20b8e740cf4bb6069376493f19ec2c974abe89f3eb53`, Update `ev_336e39ceee365e07dbeb75727bc070f9d0a2e015883420d2c95728f5bbfd0fac`.

With nonzero converted rate and live count `+0x190` zero, source `chunkName+0x158` selects a new ordinary `Particle` at `0x140065d5f` or `ChunkyParticle` at `0x140065d3a`. The constructors call base `Particle::initialize` at `0x1400606d1` or `0x140060316`; Chunky may construct and attach its named model Gob. Single appends the new pointer to live list `+0x188/+0x190` through `CExoArrayList<Particle*>::Add` at `0x140065d6b`, then tail-jumps to `PartEmitter::chkRandom` at `0x140065d88` for optional atlas-start RNG. Unlike the Fountain/Explosion allocation paths, this Single first-use path has **no second virtual initialize call**, no movement callback, and no reuse-list operation. Allocation success, model resource presence and actual atlas randomization are runtime/asset gates. Evidence Update above, Particle constructor `ev_01be66a3f5a75faf347038ce3feb1cc250c0cfb92103184508e129fcf7d21cd3`, Chunky constructor `ev_a835c7c30c035c6d53c1f634d31e77e7825f252efc92bccc6a08a310d2e47917`, atlas helper `ev_0d319e3bfd443ed59db1b8f7bc74500510aa112b058457cd319f65fa205f0dba`.

With nonzero converted rate and a live pointer, Update adds capped delta to that particle's age `+0x74` at `0x140065d9a..0x140065d9f`. If lifespan instance `+0xac` is positive, age beyond lifespan resets to zero **only** if source `loop+0x16c` is nonzero (`0x140065db4..0x140065dcb`); if lifespan is nonpositive, negative age resets to zero. It then advances particle rotation `+0x1c` by delta times instance `particleRot+0xbc` and wraps it by one revolution at `0x140065dce..0x140065e07`. Render mode `6` additionally blends saved position `+0x64..+0x6c` toward current position `+0x10..+0x18` using instance `+0xe8` at `0x140065e0c..0x140065e85`. Finally it tail-jumps through instance movement callback `+0x170` at `0x140065ea4`. `Initialize` installs standard movement `0x140068010`, P2P gravity `0x140067340`, or P2P Bezier `0x140066940` according to authored flags, so the active target is data-dependent. The update does not expire or recycle a still-enabled Single particle when its age exceeds lifespan. Evidence Update above, initializer `ev_8196177995dbdc99839bcacb411d86473a8f877c6bf8291aea000762832be32d`.

When integer-converted rate is zero, a positive live count causes removal of the first pointer from the live array at `0x140065eb0..0x140065ede`; virtual destructor `+0` is called with delete flag `1` at `0x140065ef3`. Constructor-backed targets are base Particle destructor `0x140060e50` or Chunky destructor `0x140060cf0`; Chunky tears down its attached Gob, whose Scene removal and descendants are in [particle lifecycle](original-particle-effect-lifecycle.md). If the live count is zero, the branch simply returns. It does not run movement, randomization or a reuse-list path. Evidence Update above and destructors `ev_14f04387fcaebaa5d3e69ee710d166c5d5f91c4bf3bb053e95a70d876d8c9da3`, `ev_a263862a0470e20022159c8daf8dfe8fae70b9d2d9f1d14267cc920fe20b91b9`.

## Scene publication and conditional graphics leaf

An admitted emitter with positive effective live count is sorted and invoked through installed render callback `+0x1b0` at Scene site `0x1400c7dae`. `Initialize` selects Standard, Linked, MotionBlurred, or `RenderNothing`; a nonempty `chunkName` forces `RenderNothing`, moving its attached model Gob without issuing this emitter's quad stream. The ordinary geometry path enters shared `PartEmitter::RenderEmitter` `0x140062900`, conditionally commits its six-vertex-per-particle stream at `0x140063ff5`, submits through `RenderInterface::RenderVertexStreamData` at `0x140064109`, its forwarding thunk `0x1400beed0`, and `GLRender::RenderVertexStreamData` `0x1400b5c20` to imported `glDrawArrays` at `0x1400b5d66` for a nonindexed, admitted stream. The shared render modes, material/shader gates and attached-Gob route are mapped in [particle rendering](original-particle-effect-render.md). A live list does not by itself prove a GL draw. Evidence Scene above, initializer above, renderer `ev_34f8fbdda88642e9a5fcc853ff16fcb539af3e4923e97fbbca235e05c24b6605`, thunk `ev_9682f759461cac1698e530425c68a1f6f64f7873fe4f153285f9011c35724cfb`, GL `ev_faed7a96ea930f48e2170d7800f7dc1d4110c2b5267b35fe6813a21dee29899a`.

Open data-dependent gates: active model/controller values, owner/fade admission, live-list state, allocation success, chunk model availability, chosen movement callback, render mode/material/shader, and driver execution. The constructor bounds fresh Particle/Chunky and Single update dispatch; it does not establish which authored Single resources are resident or their frame-by-frame population.
