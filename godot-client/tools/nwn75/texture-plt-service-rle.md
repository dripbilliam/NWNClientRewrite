The PLT service requires a nonnull `CRes+0x20` buffer, unset service state at `+0x68`, and null `+0x78/+0x80` pointers. It records the buffer at `+0x80`, checks header word `0x20544c50` (`PLT `), stores the payload start `buffer+0x18` at `+0x78`, and stores `CRes+0x30-0x18` at `+0x70`. A zero header field at buffer `+0xc` takes the uncompressed path, sets `+0x6c` to that payload length and clears the separate-buffer flag. A nonzero field calls `CResPLT::ReadRLEPLT` `0x1400fabf0` at `0x1400fabba`; failure invokes virtual `+0x18` at `0x1400fabc9`, resolving to `OnResourceFreed` for this subtype, then returns zero. Success sets serviced state `+0x68` and returns one. Evidence: service body/assembly `ev_3f915b0f9d46d3305066feb9e909aa9232ee6db8c5aff31731fcc3280b51f699`.

`ReadRLEPLT` saves the compressed input pointer, calls the CPU allocator `0x140c10368` at `0x1400fac0d` for the current `+0x6c` byte count, then decodes repeated-byte packets for headers with the high bit set and literal packets otherwise until the produced count reaches `+0x6c`. It stores the new buffer at `+0x78` and marks separate-buffer ownership at `+0x60` on success; `OnResourceFreed` `0x1400fab20` conditionally frees that owned buffer at `0x1400fab38` and clears the header/data state. The fresh constructor and freed hook both zero `+0x6c`, while the serviced body sets `+0x6c` only in its uncompressed arm. The observed RLE call therefore does not by itself prove a nonzero output size for a fresh resource. Source payload validity, allocation behavior for zero bytes, and any later reuse state remain outside this static proof. Evidence: RLE body `ev_3e93a5e6846582f2aa2bcffbeb65bdca49d766dee04c6a830c69b7c412a9dd47`, freed hook `ev_ecdd721c41c57acbdd7fc32ec0d2baea8fe986c803a270bfe1744adfff1c51a7`.

The serviced hook and RLE decoder are CPU-only. PLT data reaches the layered raster getter after a successful demand; texture conversion and GPU publication remain separately gated by the active material, image and Scene draw paths. No runtime PLT frequency, decoded asset mix or frame cost is established here.
