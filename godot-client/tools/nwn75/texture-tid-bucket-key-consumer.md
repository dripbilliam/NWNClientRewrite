This closes the concrete texture virtual targets left open in [bucket classification](bucket-classification.md) for the mesh/fade producer. The [texture RTTI census](texture-rtti-primary-vtables.md) bounds the two constructor-backed primary classes; it does not exclude RTTI-stripped or external classes.

An admitted fade Part calls it at `0x1400d75f6` only after positive tile fade. Both constructor-backed tables have that exact target: base slot `0x140d90c80` and Basic slot `0x140d90da0` each contain bytes `00 bb 0e 40 01 00 00 00`. The getter returns reference field `+0x18`, or self when absent. After `AurTextureGetNULL` at `0x1400e8bb4`, identity with the null singleton returns TID zero. A different pointer reaches computed `+0x8=AsCAurTextureBasic` at `0x1400e8bc4`. Base table slot `0x140d90c78` contains `00 5a 0e 40 01 00 00 00` → null-return `0x1400e5a00`; Basic table slot `0x140d90d98` contains `10 5a 0e 40 01 00 00 00` → self-return `0x1400e5a10`. The admitted Basic route reads its TID at `Basic+0x6c`; no GL call occurs in these getters. The four table qwords were read directly from the pinned PE. The body has no null guard after `AsCAurTextureBasic`; a non-null, non-singleton base object would dereference null on this static candidate path. The normal reference-to-Basic invariant is not proved by this function alone.

`AddPartToMeshBuckets` and `AddPartToFadeBuckets` use the returned unsigned TID as the index into `_meshbuckets` or `_fadebuckets`, growing the Bucket array only when needed and then appending the Part. Later `Scene::AddPartsToDrawBuckets` walks `AurTextureGetOrdering`'s ordered TID list and takes those same arrays toward [draw-item classification](bucket-classification.md). This ties referenced Basic texture identity to the grouping key, while actual resource choice, null/reference state, active TID, bucket occupancy and frame draw remain runtime selectors. The TID accessor has no image-upload call in its body, but its `AurTextureGetNULL` child may lazily acquire `NullTex`; that first-use resource boundary and other [texture publication](texture-publication-per-frame.md) routes remain separate.
