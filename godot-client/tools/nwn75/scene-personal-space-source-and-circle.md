`Scene::AddPartsToDrawBuckets` `0x1400c38f0` calls `GetPersonalRadius` for an admitted visible, positive-alpha Gob when **either** `renderpaths` or `renderpersonalspace` is enabled, writing to Gob `+0x144` at `0x1400c42b4`. `FUN_140800f70` `0x140800f70` gets the creature from `Gob::GetExternalData`; when nonnull, it reads a row index from creature `+0x300 -> +0xcc`, takes a `C2DA` table through `g_pRules+0x130 -> +0x100`, builds the `PERSPACE` column name, calls `C2DA::GetFLOATEntry` `0x1401a6c70` at `0x14080102f`, and stores the float to Gob `+0x144`. The 2DA getter linearly compares column names case-insensitively, validates row bounds, parses the selected cell/default into a float, and writes zero for an empty cell. ## Scene admission and GL boundary

`Scene::RenderSinglePass` calls `RenderPersonalSpace` `0x1400d0080` only under the **combined** global `renderpaths || renderpersonalspace` gate. The method itself stages and restores render state even if no Gob passes. It scans the **full Scene Gob list** at `+0x130/+0x138`, not the earlier admitted draw bucket. A Gob draws only if `(renderpersonalspace || Gob+0x198==1) && Gob+0x144>0`. The per-Gob flag alone therefore cannot reach this method while both global flags are off. Each admitted Gob pushes a matrix, transforms to its stored position `+0xa8`, calls `RenderInterface::DrawCircleBound` `0x1400bea20` at `0x1400d025b` with the radius, fixed color and `billboard=false`, then pops the matrix. Evidence: pass `ev_38ddb8deb96e6e243ae10dd0731f287296819d21c9d48026585c5db55412faa0`; caller gate [single pass](render-single-pass.md).

`RenderInterface::DrawCircleBound` is a jump thunk to `GLRender::DrawCircleBound` `0x1400b08f0`. On the first call, guarded by global `0x14140aab4`, it creates a 64-vertex static VDO token at `0x14140aaa8`, computes circle coordinates at angular step `0.09817477` (2π/64), writes and commits the geometry, and marks the cache initialized. Later calls reuse that VDO. Per draw it pushes/translates/scales the matrix by the radius (the admitted `billboard=false` branch), updates cached color/state, and calls `GLRender::RenderVertexData` `0x1400b59b0` at `0x1400b142e` with primitive `6`. Original primitive table `0x140d8ad20` maps index 6 to OpenGL enum `2` (`GL_LINE_LOOP`). The existing [geometry/draw boundary](geometry-and-draw-boundary.md) follows the nonindexed VDO route to imported `glDrawArrays`; the specific item-index state is selected by `RenderVertexData`. The static vertex circle is not rebuilt for every Gob. Evidence: thunk `ev_ba3e569a8a387b53546195f8388f17a1bc17f37525d7b778b5a26baf6326514e`, implementation `ev_5ea51bf57ea6a8e6303d1d5f1784a8d6309c914cb586886810a292877434bacf`, primitive table `ev_86029388673407b6b80a9ce6cdea01e45dc807d026f86191208263f57ea2e915`.

The precise producer of Gob `+0x198`, whether particular creatures have positive `PERSPACE`, and whether the full Scene list includes stale radius values after draw-bucket exclusion remain dynamic boundaries. No measured FPS significance follows from this optional branch.
