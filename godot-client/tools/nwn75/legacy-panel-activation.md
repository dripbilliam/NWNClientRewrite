# NWN-75 original legacy panel activation and widget ownership

Scope: the installed `nwmain.exe` with SHA-256 `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. Image virtual addresses and REA evidence refer to that binary. This is a static branch map, not a census of panels visible in a frame. The machine-code targets for 81 named panel vtables are recorded in [legacy-panel-activation-ledger.json](legacy-panel-activation-ledger.json).

## Activation and three distinct registries

`CGuiPanel::Activate` `0x1401fbe70` loads the layout when its flag is set and its root model is absent. It invokes the panel virtual `+0x8` `InitializeModel` before creating/attaching the `sceneGUI...` view and model, adds the panel through `CGuiMan::AddPanel`, registers the panel for updates, then invokes `+0x120` `Reposition`, `+0x60` `PostAttachmentInitialize`, closes the loaded layout, and invokes `+0x100` `OnActivate`. REA `ev_52ba1f7c007232b0c1e8620369f2a4339d8189a989eab7aa770a414367b2c78c`.

`CGuiMan::AddPanel` `0x1401f40f0` checks `panel+0xa0` for existing membership, inserts the panel in its active linked list, stores that node at `+0xa0`, and adjusts panel model depth when necessary (REA `ev_a67b772ea071bf6c0ee87a029aa00eec3efde79a2028be87272b6ec6dc617319`). This active list differs from the manager's registered update-object list, which is visited through virtual `+0x58`, and its registered scene-view vector, whose cameras are invoked through virtual `+0x10` in the render phase. `CGuiMan::UpdateAndRender` `0x1401f70e0`, REA `ev_e89c777fe9978d01554dbfdb34e21733672c56e4a3eb34090604337158400564`. Therefore panel registration itself does not execute a per-widget immediate draw loop; the attached scene models and `StringGob` objects become render candidates through the scene-view camera route documented in [legacy-gui-draw-ownership.md](legacy-gui-draw-ownership.md).

The base `CGuiPanel` vtable is `0x140db3650`. Its `+0x40` `AsGuiPanel` target is `0x1401edc60`, used as the panel signature in the named vtable census. Base `+0x8` `CGuiObject::InitializeModel` `0x1401e58d0`, `+0x60` `CGuiObject::PostAttachmentInitialize` `0x1401fb400`, `+0x100` `CGuiPanel::OnActivate` `0x1401f0980`, and `+0x120` `CGuiPanel::Reposition` `0x1401eff20` have empty bodies (REA `ev_97f6781aaaf648f6669ad6e404683214b7b99ffa3286ba407d06cff0eb50c6ca`, `ev_1678c8a5f45ac4a89d2520ea2212c1121cbd6a8c65186b3c517611d820aa7421`, `ev_277b8470d0e122ce0cfcf7d0109899ec9cce32ccb572c7bb94bb32968160aae1`).

Starting with the 84 named Panel/CPanel candidates in `gui-update-vtables.json`, reading pinned PE qwords and requiring `+0x40` to equal `CGuiPanel::AsGuiPanel` leaves **81 confirmed named panel tables**. Three name matches are not panels under that signature. Across the 81 tables, `+0x8` has 19 distinct targets, `+0x60` has 47, `+0x100` has 7, and `+0x120` has 13; there are 86 distinct addresses in their union. This bounds named static targets only. The ledger pairs each table and target with the original address/name evidence.

## Panel overrides and child traversal

Six distinct `OnActivate` overrides occur among the named panel tables (eight panel tables override the base). OptionsPanel `0x1408305c0` updates UI state; ExaminePanel `0x140898dc0` captures keyboard ownership; StorePanel `0x14097ca50` and BarterPanel `0x14097e030` notify client services; BuySellConfirmPanel `0x1409aaba0` obtains item text and registers an embedded child updater. These are activation/state producers, without a direct GL draw in the analyzed bodies. REA respectively `ev_ad23614a5bc7430e6533809e56a4bbb7903533ed772ee14597498b57c9a10768`, `ev_c446c503cabd3b0f2e647b7d9ff67f1accc692ae7af91c3ace6d07a30ff7c1ec`, `ev_9e66a90afa7ff7fe70cd57e62752fda26d7c8e441e05554f3ece6eed198cd12a`, `ev_2359a3de420000ff64bf9224d8972e9d863563e6a1ae9c4c067558551fbf6561`, `ev_bac4242b29d9985ab0652d0418f4249cf8db0f0db6b63eeb0d706fa7fea3c151`.

The sixth target, `CGuiPageControl::OnActivate` `0x1401ef8b0`, is shared by JournalPanel, CharSheet and `CenteredPanel<CGuiPageControl>`. It uses the selected child page at `+0x140`, verifies it as a panel through virtual `+0x40`, and sends it an activation event (REA `ev_88bfe14a889d9cb8c07490aab5f88871c4bbdf686b05b7d7dcb6a5712c3edf33`). JournalPanel `PostAttachmentInitialize` `0x1408853e0` installs three pages and selects one; OptionsPanel `PostAttachmentInitialize` `0x140830b50` imports several layout widgets and sets text. REA `ev_41200b303fda79c2ba9479f835128a1d3746ba1caf97be00c446373b2d931c5a`, `ev_f654c5934c5fbe54b7c714d5e56b616819cfa9dfc349ac580a50706bf537cedb`.

`CGuiPageControl::AddPage` `0x1401ed740` stores `(page object, callback)` pairs in its `+0x100` array. `SetPage` `0x1401f0300` calls `HandleSetPage` `0x1401eeef0`, which detaches the old page model, invokes the selected callback, stores the returned page at `+0x140`, and attaches its model to the parent panel model at the `pages` hook. REA `ev_eaa99c56bc7a573208a036fae1b03012556cdcbdfd9d43b36d9f32afd2329783`, `ev_1da1c53ab4695622753122e494bf182d866323b2741b1645f3a109096d62a00a`, `ev_675b023af1f150a71779e6c5965d1a105a7d62b104f3cc6159c2e05513eda9aa`.

The JournalPage callback `0x140884b40` is one concrete stored target. It caches/constructs an `CActiveQuestPage` for index 0, a `CNotesPage` for index 2, and a `CDoneQuestPage` for the remaining branch. The notes branch loads `JNL_PAGE_NOTES`, imports its `TextBox` widget, attaches scrollbar models, and focuses its edit control. The active/done branches register their new page objects for updates and select their tab. REA `ev_1fb9869fa194ec102ad921b67adb8280676212116c098c0d89dcd1a38caf192b`.

`CGuiObject::ImportLayoutData` `0x1401fe0b0` is the widget bridge: it finds a named tag in the panel, claims the tag's model for the widget, records the parent panel, enables/associates the model, copies its name, and invokes widget virtual `+0x8`/`+0x60` and `+0x48` when data exists (REA `ev_e6e9de01e521e79bc8521ddca974b494f681f27181b8dfffefa55ce7ae41ffcd`). The resulting model parts reach `glDrawElementsBaseVertex` or `glDrawArrays` through `Gob::Render`/Part rendering, while attached labels reach stream draws through `StringGob::Render` → `CAurFont::TextOut`; the exact condition and GL leaves are pinned in [legacy-gui-draw-ownership.md](legacy-gui-draw-ownership.md). That scene path is conditional on attachment, visibility, Part subtype and camera gates.

## Open edges

The 81 named vtables do not prove the runtime active panel set or enumerate unnamed panel classes. The remaining subclass `InitializeModel`, `PostAttachmentInitialize` and `Reposition` targets have not all been followed to their widget mutations. Other page-control callbacks have not been exhaustively enumerated. The GFF resrefs and hook attachment outcome remain data-dependent. These limits prevent a claim that every named panel or child yields a GL call in a given frame.
