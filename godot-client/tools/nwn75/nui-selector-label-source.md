## Render and API boundary

`Nui::Window::RenderAll` `0x1406c4b20` iterates its weak registry and calls `RenderWindow` `0x1406c5350` at `0x1406c5137` only for its surviving/renderable candidate. `RenderWindow` rejects its close flag `+0x11c`, performs window/context state work, then calls render virtual `+0x60` at `0x1406c65a9`. The constructed `enable_make<Nui::Debug::Selector>` vtable `0x140e31328` maps that slot to `0x140701050`. The exact registry population, active/open flags and per-frame visibility remain runtime unknowns. Original REA `ev_fdd4a2429d1f0bc34d80bd3dadc79ae2cbe7531002b9758ca8a00086277d1cbe`, `ev_75101c46db8fe527f673a2bc4ee7f55f305ad291320da94ce352c6dd2c02fb47`, vtable `ev_970309c3bce6ea8275ed8b5611dc7718361564e42ad2d33fe7be747682a40fba`.

The per-frame GUI path invokes the Nui pass from `CGuiMan::UpdateAndRender` at `0x1401f76e1`, subject to manager `+0x2c != 0`; thunk `0x1406c39e0` jumps to `RenderAll`. `RenderAll` returns when global UI bitmask `0x141296d08` is zero (`0x1406c4b59`). A registry weak reference must lock, the window must survive stale/close pruning, and its membership mask at `+0xb0` must intersect that global mask (`0x1406c4fe2`/`0x1406c4fe9`). It initializes virtual `+0x40` once when `+0xb8` is zero, calls `UpdateWindow` at `0x1406c5128`, and calls `RenderWindow` only when the qword at window `+0x8` is zero (`0x1406c512d`/`0x1406c5137`). `RenderWindow` itself returns before the virtual draw when `+0x11c` is set. These are exact code gates; static evidence does not prove that the Selector passes them in any particular frame.
