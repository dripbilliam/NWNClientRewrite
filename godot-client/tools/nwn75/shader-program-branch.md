`GLRender::LoadShader` first compiles the named vertex (`0x8b31`) and fragment (`0x8b30`) sources. If either compile returns zero, it instead compiles `vs_invalid` and `fs_invalid`; a nonempty optional name selects a geometry (`0x8dd9`) shader. It calls `DAT_1414424f0=glCreateProgram` once at `0x1400b465c`, then `DAT_1414424d0=glAttachShader` at `0x1400b4683`, `0x1400b468f`, and conditionally `0x1400b469e` for geometry, before `ConnectShaderData` links and queries the program. Both pointer globals are assigned by original `FUN_140b7a350` through `wglGetProcAddress`; their four targetless callsites are thereby resolved. Evidence: REA `ev_bf802e73`, loader `ev_34f0426e`.

`GLRender::LoadAndCompileSingleShader` obtains the authored `.shd` source through `FUN_1400b46d0` `0x1400b46d0`. That helper calls named `AurResGet` `0x14005dbc0`, copies the returned bytes into a null-terminated buffer, then recursively replaces each `#include "name"` (scanner width 16) with another `.shd` resource; a missing include frees buffers and fails the source load. The named `AurResGet` callback/local-file fallback is traced in `model-instance-branch.md`, with generic archive storage in `model-resource-storage.md`. The compile helper prefixes a generated GLSL 330 header with light/bone counts and current shader flags, then passes two source strings to `CompileShader`; a source miss logs and returns zero. This is a conditional program construction/reload path, not an unconditional per-frame file read. Evidence: REA `ev_a8bdacbc`, `ev_696731de`, `ev_bf802e73`.
