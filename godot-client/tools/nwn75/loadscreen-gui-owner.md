## Teardown and limits

The owner replacement branch (`param_4 != 0` and existing owner `+0x448` panel) invokes the panel's first virtual slot with delete flag 1. The constructed `CGuiAreaLoadscreen` vtable slot `0x140e4c0a8` resolves to destructor `0x1408371d0`. It unsets modal, releases the three label string wrappers and their widget models, destroys the status bar widget, then calls `CGuiPanel::~CGuiPanel` `0x1401fbc80`. The label wrapper owns a `NewCAurString` interface; its virtual destructor slot leads through adjustor `0x14004753c` to `StringGob` destructor `0x1400475f0`, which deletes text, releases its font reference and calls `Gob::~Gob`. `CGuiPanel::~CGuiPanel` deactivates when active, removes view registration only when it owns a view (`+0xc0 != 0`), and calls `CGuiObject::~CGuiObject` to release the root model. Since the base constructor sets `+0xc0=0` and the examined `SetSceneView` only writes `+0xb8`, the borrowed manager view is not deleted by this observed path.
