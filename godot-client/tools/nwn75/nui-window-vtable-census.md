# NWN-75: original Nui window dispatch census

Status: partial original-binary branch map. The machine-readable [vtable census](nui-window-vtable-census.json) records 43 pinned original tables, their `+0x40` initialization, `+0x58` update and `+0x60` render targets, and a read-bytes evidence ID for each. These tables were found from incoming data references to base initializer `0x1406c34a0` plus the two separately established JSON window tables. This is a candidate table census, not proof that every class is registered or drawn in one frame, and other initializer overrides may remain.

`Nui::Window::RenderAll` `0x1406c4b20` makes its one-time initialization call at `0x1406c511a`, then calls `UpdateWindow` `0x1406c79a0` and conditionally `RenderWindow` `0x1406c5350`. The latter reaches each registered, visible window's render slot. The 43 tables reduce to 13 distinct initializer/update/render triples; many `enable_make<T>` wrapper tables duplicate their underlying class targets. The base initializer restores persisted geometry under its configuration gates; JSON windows instead construct JSON content in `0x140746f00`. See [GUI presentation](gui-presentation.md) for those routes.

The debug render slot functions call familiar Nui text and control producers such as `0x140a86280`, `0x140a86340`, `0x140a86630`, `0x140a76d50` and `0x140a77ae0`; `0x140a86280` measures the string and forwards it to `0x140a8ff00`, already followed to the kind-16 command allocator. The action calls in the resource, DM, Steam and sound windows are side effects of their UI state, not additional GL draws. The source does not establish whether these debug windows are open during ordinary Arelith frames.

`UpdateWindow` reaches the class update slot `+0x58` at `0x1406c80dd`. The base target `0x1406c7610` tests a stored object/predicate and can detach it through virtual `+0x20` when virtual `+0x10` returns false; this is lifecycle cleanup. The debug selector override `0x140701890` calls `FuncInterp` with `perfstats_show frame` or `perfstats_show second` when its mode field is 1 or 2. The NWSync housekeeping override `0x1408b5bd0` calls `NWSync::CNWSync::AsyncHousekeeping`, copies result state, and may mark the window to open under its flags. The ContentIndex browser override `0x140940150` scans its entry array. If it reaches the end, the array is nonempty and a refresh byte at `+0x550` is set, it clears that byte, invokes `0x140940590`, obtains the app-manager string, and conditionally refreshes several browser selection/result vectors from queued fields at `+0x518` through `+0x548`, clearing each consumed field. It may mark the current window for reopening under its state gates. An entry with both the tested status byte and pointer empty exits before this refresh work. Its underlying browser data and event helpers remain open. These update targets are distinct from the render slot's numeric command producers.
