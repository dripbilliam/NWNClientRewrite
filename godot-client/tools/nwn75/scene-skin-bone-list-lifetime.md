It records static original behavior, not a measured per-frame cost or a live Skin population.

`PartSkin::Draw` reaches `RenderSkinned` `0x1400e0410` after its material and renderability gates. `RenderSkinned` calls Skin `+0xd8=PartSkin::PostProcess` at `0x1400e044f`; the heavy postprocess returns immediately when MdlNodeSkin `+0x278` is null. Its temporary-array remover clears that pointer after the setup branch, so this call does not itself prove repeated geometry rebuilding. `RenderSkinned` reads the MdlNodeSkin bone count `+0x284` at `0x1400e0455` and skips bone gathering and draw when zero. On the positive path it initializes three process-global list objects once through local-static guards, then zeroes their logical counts at `0x1400e04af/0x1400e04b5/0x1400e04bb`. The actual `GatherBones` arguments are vector list `0x14140b208` and quaternion list `0x14140b1d8`; the third reset list at `0x14140b1f0` is not passed to this call. Their backing pointers and capacities are retained when the counts reset. The registered exit routines `0x140d79090` and `0x140d78ff0` free the vector and quaternion backing pointers, respectively. `GatherBones` `0x1400df000` composes each visited Part's position/quaternion into the inherited transform, appends one 12-byte Vector and one 16-byte Quaternion, then scans the Part child array at `+0x38` with count `+0x40`. It recurses only when child source node `+0x60` matches parent source node pointer `+0x8`; the exact conditional recursive call is `0x1400df162`. Each append compares logical count with capacity. A full Vector list calls `CExoArrayList<Vector>::Allocate` at `0x1400df0ab`; a full Quaternion list calls its corresponding allocator at `0x1400df0e7`. Both begin at capacity 16 and double capacity when full. Their allocators create a new array, copy existing entries and free the prior backing pointer. No allocator is called on an append within capacity.
