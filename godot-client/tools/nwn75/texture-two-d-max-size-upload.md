# NWN-75 2D texture maximum-size upload

Pinned original `nwmain.exe` SHA-256 `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. This follows the connected 2D Basic texture publication path from [texture acquisition](texture-acquisition.md) and [per-frame publication](texture-publication-per-frame.md), concentrating on source dimensions larger than the renderer's GL texture limit. The Basic getter vtable and extension cells are already bounded in [the 2D indirect-call census](texture-create-indirect-callsites.json). Other texture subclasses and live image sizes remain runtime boundaries.

`CAurTextureBasic::glImageBasic` `0x1400ee1b0` calls `RenderInterface::CreateTexture` at `0x1400eecdd` for the ordinary 2D path; the wrapper `0x1400be960` tail-jumps to `GLRender::CreateTexture` `0x1400af440`. The GL body gets source dimensions, bytes per pixel, image pointer, tile counts and width through Basic virtual getters. More than one X or Y tile calls `ImageGetSubImage` at `0x1400af53c`, which allocates a tile-sized buffer and copies source pixels. A single tile borrows the image pointer instead. The first call while global maximum-size cache `0x14128eafc` is `-1` invokes imported `glGetIntegerv(GL_MAX_TEXTURE_SIZE=0xd33)` at `0x1400af561`; a reported zero becomes `0x1000`. Later calls use that cached value without querying GL in this body. With `GetCompressedSize()` nonpositive, the body selects an uncompressed GL pixel format by bytes per pixel. For either tile dimension greater than the cached GL maximum, it right-shifts that dimension until it fits, allocates `reduced_width*reduced_height*bytes_per_pixel` at `0x1400af8e8`, and loops over output pixels and channels. Its nested loop sums a rectangular source block and writes the rounded mean; this is CPU resampling before GL upload, separate from any resource decoder. When both dimensions already fit, it uses the original tile pointer. Without mipmap generation, the caller's update flag chooses imported `glTexSubImage2D` at `0x1400afb0a` or `glTexImage2D` at `0x1400afb37`. With mipmaps enabled, it sets base/max-level texture parameters, calls `glTexImage2D` at `0x1400afabd` and extension `glGenerateMipmap` at `0x1400afac8`. It frees the downsample buffer at `0x1400afb78` when separately allocated and the tile-copy buffer at `0x1400afb8a` when separately allocated. Thus oversized uncompressed image publication can include one tile copy and one full CPU downsample before the GL call, but neither operation is present for a fitting single tile. With positive `GetCompressedSize()`, the body takes a different maximum-size path: it advances over authored compressed mip payloads, using `GetNumMipHeaderBytes` and `GetCompressedSize(width,height)`, until the selected width and height fit. It then calls extension `glCompressedTexImage2D` for the admitted base level at `0x1400af745` and for additional authored mip levels at `0x1400af800` when enabled. It does not run the uncompressed CPU box filter in this branch. The active format, source mip count, size-limit cache, tile count, update flag and selected image are runtime inputs; this static branch does not establish how often either upload mode runs. Evidence: GL body above and the [getter/extension callsite census](texture-create-indirect-callsites.json).
