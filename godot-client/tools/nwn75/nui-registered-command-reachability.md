# NWN-75 original registered Nui content and command reachability

Scope: installed `nwmain.exe`, SHA-256 `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. All addresses are original image VAs. This document connects **static publisher candidates** to window render targets, layout targets, numeric command producers and GL leaves. It does not establish which windows were active in a specific frame.

## Registry publishers to render methods

`Nui::Window::RenderAll` `0x1406c4b20` walks the identifier-keyed weak-window registry rooted at `0x141422c00`. Under its UI-enable and per-window lifetime/open gates it initializes a surviving window once, updates it, and passes the renderable window to `RenderWindow` `0x1406c5350`, which dispatches its virtual render `+0x60`. Stale/dying entries can be erased before this render. REA `ev_fdd4a2429d1f0bc34d80bd3dadc79ae2cbe7531002b9758ca8a00086277d1cbe`, `ev_74d8d73453f582b8c256a0045e8858e65c2aa3a509fd2f4eefec94eae3f35817`; registry owner details in [nui-registry-ownership.md](nui-registry-ownership.md).

The [publisher type ledger](nui-publisher-type-ledger.json) resolves **all 31 pinned direct calls** to registry map `operator[]` `0x140700210`. In each containing body the constructed `enable_make<T>` owner is followed by the weak object/control-block writes into the returned map slot. The formerly unclear last callsite `0x1409dc953` constructs the downloader through `FUN_1409db670`, which installs its `enable_make<Nui::NWSync::Downloader>` vtable (REA `ev_755941c51c3b421cfcbf9f247f0b029581f5d419d0249fb37b64ad318e73abfc`, delegate `ev_f49a84a5e6c62151b9b85fd5e1f220c50210be8b25a3e2aa35bd5a865ea19fa2`). The 31 callsites construct **21 distinct named window types**: 20 callsites have the base render target `0x1406c44e0`, while 11 have one of ten override targets. These counts describe possible publications, not simultaneous windows or calls per frame. The full callsite, type, REA and vtable evidence is in the ledger; [nui-window-vtable-census.json](nui-window-vtable-census.json) contains the render-slot qwords.

Those override bodies can produce Nui commands without passing through window content `+0x20`. The independent static publisher proof narrows the registry candidates to named constructed types but does not eliminate indirect publication or runtime-constructed types outside the direct-call census.

## Content and child target families

The [RTTI/vtable ledger](nui-layout-rtti-vtables.json) scans pinned `.rdata` using MSVC x64 Complete Object Locator self-RVAs and TypeDescriptor names. All eight concrete class names directly in the `Nui::Layout` namespace that match this RTTI pattern are represented. Their content `+0x20` targets reduce to four addresses: `0x140950d90` (`LayoutGroup`, `SingleGroup`), `0x140951260` (`Layoutable`, `Span`, `SelectList`), `0x1409528e0` (`Widget`, `StatefulWidget`), and `0x14095b1a0` (`MoviePlayer`). Their child `+0x28` slots reduce to `0x140950580` for the two groups and `0x140950d10` for the other six. This is a complete census for the specified RTTI class-name pattern in the shipped `.rdata`, not a proof that other unnamed or RTTI-free objects cannot be installed. Original read-byte evidence is paired with each row.

`Nui::Window::Render` `0x1406c44e0` requires non-null content at `window+0x108` before its virtual `+0x20` call (REA `ev_daabb01e3b637193b6eafc330825d4cbb65b3affd3c3ac9e9de6028146e8097b`). The shared installer `0x14074c0b0` preserves an already-group content object or wraps a non-group child in a `SingleGroup`, retaining the strong owner at window `+0x110` (REA `ev_2f28694d29789d72db7d1c593570250dcb5a3d78b7908452ea8256ebe0f4801a`, `ev_f54583d451dab0323abec3d97c94dd3f5f6c361c82ab8ba41b74b4b6b2fc5eb1`). Existing evidence proves a `SingleGroup` for the QueryDialog construction and for JSON's non-group wrapping branch. Other installer callers accept supplied layout values, so their exact group subtype remains conditional.

Group render `0x140950d90` begins a Nui group, conditionally recomputes layout and invokes child `+0x28`, then reaches group/content descendant `0x140951260` through virtual `+0x38`. The latter visits stored children and invokes child virtual `+0x20` at its render point after size, clipping and callback work. It also conditionally emits its own border/background numeric kinds: filled rectangle **5** via `0x140a82050`, outlined rectangle **4** via `0x140a8c120`, and nine-slice textured image **17** via `0x140a7d2e0` → inline writer `0x140a67830`. The exact branch depends on layout/visibility/style fields; its many other callback and layout effects are not all GL draws. REA group `ev_8349061de9d3bbf73c9f3aa261147274cb6ad791445126e81f2fdeef157ab41e`; content retained dossier `ev_fad75cefad3cd5f81b65559a485d8c263e4b4dddc0ad801c7d6dbbc2cf0195da`; writer `ev_7c927d99bfa67d10319a3dfebdc21eb0dc6d58a9d410edac3d634f5308218551`.

`Widget` and `StatefulWidget` `+0x20` target `0x1409528e0` reads the stored function object at `widget+0x6f8` and invokes its virtual `+0x10`; it aborts if that pointer is absent (REA `ev_36c2885cff10e09a952779a2ab49478bab1ecb41b5421104f5595660b713de86`). Therefore the shared Widget vtable alone cannot identify a command. The JSON factory `0x140741070` has at least **19 literal type branches**. [json-widget-callbacks.md](json-widget-callbacks.md) and [nui-content-continuation.md](nui-content-continuation.md) bind known constructor-installed function vtables to text, button, image, slider, progress, combo, list, chart and movie paths. These paths conditionally produce numeric kinds 2, 4, 5, 8, 12, 16 and 17; the movie widget directly reaches line, rectangle, text and image producers. The `SelectList` options/tabbar path uses `0x140951260`. Exact JSON data, callback selection and layout state remain data-dependent.

The numeric converter `0x140a7c340` consumes emitted command kinds and generates CPU vertex/index geometry. The draw routine `0x140a71760` maps buffers and calls imported `glDrawElements` for a nonempty converted draw command, with texture/scissor state around it. This is the conditional GL leaf reached by the documented Nui command families; a constructed window or callback alone does not imply a draw. REA converter `ev_ad209304a0b1e3d9ce73250523f0be0b533a57ffa37433b89d53a3d9236ce940`, draw `ev_6b5e1be5df3d0ec1c19e05d9f5114d2a9453a5c0bd89c9f09f1a3012d4826278`.

## Remaining exact edges

1. Runtime registry population, per-window open/visibility state, and owning OS thread are not established by static constructors or weak-pointer publication sites. The direct-call census does not exclude an indirect publisher.
2. Several base-render classes supply layout objects to `0x14074c0b0` whose concrete subtype and child tree are data-dependent. The eight RTTI class targets bound the known namespace family, but not the exact active object at each callsite.
3. Stored Widget callbacks outside the mapped JSON/known constructors, group before/after function objects, and source-data-dependent child lists remain dynamic. Some command producers lead to resource, input or non-graphics effects; these require separate descendant closure.
4. Numeric kind 18's command-embedded callback remains a separate unresolved producer/target condition in [nuklear-kind18-callback.md](nuklear-kind18-callback.md).
