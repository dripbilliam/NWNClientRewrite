`0x14095c970` reads the captured float from a direct pointer, an installed generator, or held fallback. When the direct pointer is absent but a generator exists, its code calls that generator at `0x14095c998`, reloads the still-absent direct pointer, then calls the generator again at `0x14095c9bc` for the value it uses. Thus that branch can execute the generator twice in one Widget render. The installed generator body is dynamic and may have side effects; no caching equivalence is inferred. The callback multiplies the chosen float by **100000.0**, converts to a 64-bit numerator (with an explicit high-range adjustment in the generated code), fixes the denominator to **100000**, and tail-jumps at `0x14095ca25` to `0x140a88a80` with mode **0**. It does not clamp the source float in this callback body. The lower wrapper requires live Nui context, active window and valid row before `0x140a64610` receives that numerator/denominator. The latter conditionally emits filled/outlined rectangles or image/nine-slice commands according to style and clip gates.
