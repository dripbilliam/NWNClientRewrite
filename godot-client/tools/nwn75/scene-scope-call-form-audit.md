# NWN-75: original Scene scope callback instruction forms

Pinned original `nwmain.exe` SHA-256 `3b7cb1252e0edb2ce22d7971f333aade027039ae30a45b4bc64732c3e6bec73a`. A pinned-byte audit found 20 scene-ledger rows formerly labeled direct although their original instructions are `FF 50 10` (`CALL qword ptr [RAX+0x10]`) or `FF 50 20` (`CALL qword ptr [RAX+0x20]`). REA supplies a computed-call target reference at each site. The ledger now classifies all 20 as `computed_callback` and records an exact `instruction_evidence_id` for each decoded instruction.

The ten `+0x10` sites enter scope-end callbacks; the ten `+0x20` sites enter conditional function-object cleanup callbacks. Pairs occur in `ManageSceneBSP`, `DoHighlightGob`, `RenderLensFlares`, `RenderDrawableSquares`, `FadeDoors`, `DoBinBucket`, `DoTriggerBucket`, `RenderLines`, `RenderPaths`, and `RenderPersonalSpace`. The first pair, `ManageSceneBSP` `0x1400dbb94/0x1400dbbad`, targets `0x1400de810/0x1400de800`; those bodies call `Instrumentation::EndScope("BSP",0)` or conditional deallocation, respectively. REA target bodies `ev_1924f60a241640b7f9228524a905b4b7e5f1528eea64529ac129eed500187608`, `ev_d7749080a11b0bdc8c72059da1dd80b9122f72f709ef68bd1dce015e703777cd`; first two instruction decodes `ev_744d536ad9c6b59c9a9764c99dae55672efe88f700cfd6e6be0dd7eb301b16d1`, `ev_7894e1581d9aa0abf5083587880c40bb01cc4ad4b49378fd992dea2166e85adb`. The other scope bodies and timing descendants are described in [render scope callbacks](render-scope-callbacks.md).

After reclassification, `audit-direct-callsite-bytes.cjs` verifies all 2,227 ledger edges still labeled E8/E9 direct/tail against the pinned PE, with zero target mismatches and zero non-E8/E9 instruction forms. This literal-byte check does not establish runtime callback reachability beyond the REA references and local function-object context.
