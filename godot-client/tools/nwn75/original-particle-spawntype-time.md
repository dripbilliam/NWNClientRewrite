## Accumulator, count and particle publication

At `0x140064cfc..0x140064d03`, Update truncates the float rate to an integer and skips both spawn schedulers when the result is nonpositive. A positive fractional rate below `1` therefore does **not** accumulate time on that frame. The source test at `0x140064d12` selects the zero arm by jumping to `0x1400650d1`. There, Update adds capped frame delta to PartEmitter `+0x198` and writes the new value at `0x1400650dc`. If it is below reciprocal rate `1/rate`, branch `0x1400650e8` returns with that accumulated value retained for the next admitted update. If the threshold is met, the code computes `count = trunc(accumulator × rate) % (trunc(rate) + 1)` through `0x1400650f0..0x1400650ff`. It runs the spawn loop only when that remainder is positive; the loop bound is recomputed from `+0x198` at `0x140065211..0x140065226`. Once the threshold branch has been entered, it zeros `+0x198` at `0x14006522c` even when the remainder was zero. The code does not retain a fractional remainder from a threshold-crossing update. Evidence Fountain above, exact instruction sequence in the same dossier.

Each loop iteration first checks the expired-particle reuse list `+0x130/+0x138` at `0x140065110`. A nonempty list supplies a recycled pointer and removes it from the list. Otherwise the source model-name byte `MdlNodeEmitter+0x158` at `0x140065171` selects `Particle::Particle` `0x140060680` at callsite `0x1400651c9` when empty, or `ChunkyParticle::ChunkyParticle` `0x1400602b0` at `0x14006519b` when nonempty. The virtual `Particle+0x10` call at `0x1400651e2` initializes either constructed subtype (`Particle::initialize` `0x140066450` or `ChunkyParticle::initialize` `0x1400663d0`); recycled pointers retain runtime subtype. `ChunkyParticle::initialize` calls base initialize at `0x1400663e9` and may publish its attached model Gob through Scene/animation/event operations. Base initialize can call `randomPosition` `0x140068d80`, `inheritVelocity` `0x140066140`, and `randomDirection` `0x140068800` under authored parameter gates; its random calls reach the per-thread CRT generator `0x140c7ed00`. The constructor and model Gob descendants are mapped in [particle lifecycle](original-particle-effect-lifecycle.md). ## Conditional draw leaf and dynamic boundary

`Scene::DoEmitterBucket` later sorts eligible emitters and invokes their installed render callback `+0x1b0` at `0x1400c7dae`. For an empty source model name, `PartEmitter::Initialize` installs Standard/Linked/MotionBlurred geometry callbacks selected by authored mode; those thunks share `RenderEmitter` `0x140062900`. It can commit six vertices per effective particle at `0x140063ff5`, then, if shader/material/fade/live-count gates pass, calls `RenderInterface::RenderVertexStreamData` `0x1400beed0` at `0x140064109`. That thunk jumps to `GLRender::RenderVertexStreamData` `0x1400b5c20`, whose nonindexed stream route reaches imported `glDrawArrays` at `0x1400b5d66`. A nonempty model name instead installs `RenderNothing`, which updates attached model Gobs; those Gobs may draw later through Scene. Exact modes, texture/shader gates and the alternative Gob route are in [emitter render callbacks](original-particle-render-callbacks-fountain.md).
