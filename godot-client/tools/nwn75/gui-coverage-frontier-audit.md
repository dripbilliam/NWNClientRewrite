## Prioritized remaining GUI frontier

1. **Active Nui content and remaining data-dependent callbacks.** Direct weak registry publishers, four content target families, two child families and 31 Widget callback tables now have static coverage in the linked supplements. The bound ConfigWindow member, recursive TreeNode and group Widget have conditional numeric/CPU leaves. Determine which window classes are active/visible at runtime and bind remaining dynamically supplied child content or event targets before claiming full per-frame reachability.
2. **Residual Nuklear context boundary.** [Nuklear resource lifecycle](nuklear-resource-lifecycle.md) and its [continuation](nuklear-resource-lifecycle-continuation.md) bind UI program, shaders, VBO/EBO and atlas creation/refresh/teardown, and find no explicit UI VAO deletion in the observed direct path. SDL's dynamically loaded shutdown behavior and any indirect context recreation remain outside the installed executable's static proof.
3. **Legacy GUI update and overlay event reachability.** `CGuiMan::UpdateAndRender` invokes registered object virtual `+0x58`; 207 named vtables use five known targets; the additional pinned RTTI scan finds 31 plausible GUI/panel `+0x58` table targets and rejects one unrelated table shape. `RegisterUpdate` has 267 static references, including 264 direct calls across 135 owner procedures. The registered-update supplement maps fade/scroll, area-map and floaty-text descendants. The separate Gob callback census identifies 26 static registrations, including one `propagaterender` handler; its later virtual-site census finds 30 fixed-offset production sites (25 CALL and five tail JMP). Registration, production and active runtime handlers are distinct sets. Resolve the active object set, remaining panel callback assignments, `StringGob::Render` attached-object producers and the active `Gob::DoEvent` handler set. REA `ev_160fec6082e355d804022c29623f8d60080296276d8491962c526d2da0e4beee`, `ev_d8e0b598f58bb00b1531799fed1dcef091ac06e012f9d6253d42dd924c3b78aa`, `ev_454d4756647ffc9a42d34b6181f506a8b3af7b68003d37757b01d3323b3481de`, `ev_c85ac0162076624f991cae9e7fd4d1607d3b95e6aeca19173385f1bf9c20fae6`.
4. **Font/resource fallback and decoder leaves.** The named-font route reaches conditional texture build, TTF bake, image wrappers, GL texture publication and reset. The [demand/decoder continuation](gui-resource-demand-decoders.md) follows TTF `CRes::Demand` through archive, encapsulated, directory and manifest source selectors; directory and initial file-backed raster reads reach CRT and Win32 file APIs. It closes TGA header/pixel read and traces JPEG scanlines through controller/color-converter output bytes. Pinned archive vtables resolve `+0x28/+0x40` to concrete size/read methods, whose compressed branch selects Zstd, zlib or null-copy providers. The CResTTF served hook returns success, and the initial raster path frees directly while the release callback is null. Deep decompressor/libjpeg entropy/upsampling/quantization and active asset/source selection remain open. Earlier ledger status labels have not yet been reconciled with the new supplement. REA `ev_5d7c92d55b6cd5dcc52fae8cadb9fc10e71b7c4d0aa03060a91a32c581d0f472`, `ev_32924882e3d890833dc71949c122dfc1643d975d0dccf55ffef24c6c22ba2027`.
5. **Conditional alternate screens and thread evidence.** Movie decode/audio and NWSync UI update are mapped to first descendants but not every CPU leaf. Static `Update`/GUI/GL call order does not identify OS thread IDs or prove each branch's frequency. Trace only the ambiguous runtime dispatches when needed; do not infer that an unloaded/disabled UI path runs every frame. Movie and downloader starting evidence: REA `ev_38fcfc901015460d4ce6c6a208e53e484c76c1709e098a17b9d73defb8ce26d7`, `ev_81565d54442f3871bd63dfc9307eca62dc91095490e08e40997344e0ccdc7a34`.

The [legacy attachment/callback continuation](legacy-gui-attachment-callback-producers.md) now proves two `CGuiListBox::SetItem` indirect `StringGob::AttachModel` reattachment callsites, while the initial nonnull model producer remains open. It pins loadscreen/credits panel `+0x88` callback assignments to active-gated `CGuiPanel::Deactivate` and traces the associated panel models/labels to conditional GL leaves. It also classifies `CStringItem::Render` as a vtable-only text wrapper and `RenderSceneViewFirst/Last` as GUI-view order mutations with concrete callers, rather than immediate draw calls.

The [standalone draw and panel animation continuation](gui-standalone-draw-and-animate-entries.md) maps five named CAurGUIImage/String Draw targets to streamed GL leaves and two client calls to `CGuiPanel::AnimateScene` → `Scene::Animate`. Its exact factory/Draw incoming-reference queries find vtable/data references but no direct code consumer of the standalone objects, so active runtime use stays open.

The ledger's statuses remain open where a named target has deeper descendants. This audit does not mark the original GUI branch or NWN-75 complete.
