This closes the exact invocation sites for four constructor-backed stack callbacks in the [class-5 manifest resource lookup](manifest-resource-lookup.md). It does not assert that class 5, a manifest hit, a shard hit or any SQLite row is selected in a live frame. The resource demand inherits its caller thread; none of these wrappers adds a queue handoff.
