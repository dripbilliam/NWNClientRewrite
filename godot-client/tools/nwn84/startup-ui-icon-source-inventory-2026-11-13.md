# NWN-84 bounded startup UI/icon inventory

Source-only review; no production edit, client run, FPS result, or residency claim.

| Resource path | Current first-use owner | Coverage/lifetime gap |
| --- | --- | --- |
| Pregame menu artwork and fonts | `native_pregame_menu.gd` creates `native_gui_painter.gd`; `native_ui_art.gd:bind` requests GUI models or rasters when controls bind | Page readiness hides incomplete menu art, but startup does not await an all-content preload. The painter owns and clears its texture dictionary on close. |
| Other menu, character, HUD, spellbook and action artwork | `native_gui_painter.gd`, `native_game_desktop.gd`, and screen owners call `native_ui_art.gd:bind/request_model` with clips, overrides, poses and regions | The model key includes these variants. A base model preload cannot cover all consumer keys. |
| Inventory and barter item icons | `native_inventory.gd`, `native_barter.gd`, `native_examine_frame.gd` call `native_item_icons.gd:request`; `native_data/item_icon.gd` derives a model/layer/PLT palette from received item parts, colors, gender, baseitems and other tables | The exact composite icon key is known only after item state and tables arrive. Owner textures persist only until owner close. |
| Effect, radial, quickbar, spell and NUI icons | `native_effect_icon.gd`, `server_radial.gd`, `server_action_queue.gd`, `native_game_desktop.gd`, `native_nui.gd` bind resource names from runtime rows | First binding still queues asset read, decode and texture creation when the key is absent. |
| Active resource stack | `native_data/resource_catalog.gd` compiles priority-ordered install, loose, module/archive and NWSync bindings; `resource_names(type)` enumerates resolved names, `raster_location()` resolves format/storage precedence | A startup inventory must use the fully mounted catalog identity. NWSync additions require a second gate after arrival and before dependent UI opens. |

The existing `native_ui_preload.gd` is a **manual** Render Settings action (`native_session_world.gd:start_ui_preload`). `native_data/ui_prebake_plan.gd` discovers GUI GFF references, six GUI model prefixes, some fonts and static model states. It says generated poses and replacement textures still need live consumer capture. The preloader saves finished images to the prepared cache, then explicitly erases each live texture and closes its icon renderer; it is disk prework, not session GPU/RAM residency. `native_ui_art.gd` and `native_item_icons.gd` still load/upload cache pixels or original assets when a new owner first requests them.

Historical `reports/native-ui-preload-cold-final-v1.json` completed 5,392 jobs: 104 GUI documents, 1,460 models, nine fonts and 3,819 saved images in 51.202 seconds. It reported four failures and four missing GUI references, and peak live private images of one. The warm run reused 3,819 images in 17.919 seconds. These are evidence for the existing manual subset and its cost, not current-source normal-client acceptance or all-icon completion.

**Decision:** A short patch that starts the existing preloader automatically or retains its one-at-a-time textures would silently redefine “all” to its static subset, omit runtime composite variants, and bypass session-wide ownership. No small safe source change meets NWN-84 acceptance. Production remains unchanged.

**Concrete next implementation step:** Build a resolved-catalog manifest per mounted content identity, recording all available GUI documents/models, raster/PLT layers, fonts, and consumer-generated keys with explicit provenance and failures. Give startup and post-NWSync phases a shared session-long strong texture owner keyed by resource identity plus clip/overrides/poses/region. Gate each applicable screen on its manifest cohort reaching decoded and GPU-ready state; never admit it on a partial cohort. Record completed/failed counts and RAM/VRAM before deciding promotion. Dynamic server item/action variants need a content-arrival cohort before their first UI presentation. The existing explicit missing/corrupt records must remain visible.
