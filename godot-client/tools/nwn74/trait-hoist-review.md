# NWN-74 RenderingDevice trait hoist, private candidate

The pinned private candidate moves `driver->api_trait_get(API_TRAIT_HONORS_PIPELINE_BARRIERS)` from inside `RenderingDevice::draw_list_draw()`'s descriptor-slot loop to immediately before it. Vulkan's override falls through to the base driver's constant `1`; the driver is created during RenderingDevice initialization and is not replaced during a draw. The same trait value therefore governs every slot in one draw. For a draw with **K** active expected-format slots, getter calls change from **K to 1** while descriptor preparation and binding order stay the same. An all-empty set mask gains one harmless getter call; the saved replay does not expose the frequency of that boundary.
