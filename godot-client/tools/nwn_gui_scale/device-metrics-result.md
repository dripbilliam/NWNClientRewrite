# Godot outbound GUI device metrics

`native_session_world.gd` now publishes a `device-properties` message with `connection`, monotonic `metricsRevision`, `guiScalePercent`, `guiWidth` and `guiHeight`. The dimensions are physical `WindowSettings.current()` size; scale is `int(WindowSettings.fixed_scale * 100)`, preserving native truncation of the requested fixed scale instead of the constrained canvas scale. The packet builder accepts native automatic scale zero and rejects malformed/nonfinite metrics.

The publisher waits for authenticated loopback `setup` or lobby reception, then sends the current metrics for connection 0 before game-server admission. The initial same-connection lobby also releases the gate; an earlier version only did so when the connection number increased, which delayed the first send until `setup`. It sends changed values after `WindowSettings.changed`, dedupes identical metrics, and re-sends on new connection/session reset with a strictly increasing revision. It does not change the visible UI scale or resize policy. Native source proof for physical dimensions is `FUN_1406dd5a0`; `FUN_1406be4c0` retains the requested `ui.scale` value across `ComputeGUIScaleAndUpdate` before multiplying by 100. Rigs65 owns the host codec and first-connected-frame send.
