# NWN-73 sky publication callback scheduling

`SkyWorld._process` previously ran every frame from `configure`, including no-sky areas and the time after a model set was published. Its only task is bounded publication once all model jobs complete and the resource pool permits it. Sky time and phase changes are driven separately by `AreaEnvironment.advance`.

The candidate disables this callback at configuration and each new selection. The last matching asset completion wakes it after the full model cohort is staged. It remains active while waiting for `pool.can_publish()`, then disables after the final publication, error, no-sky selection or retirement.
