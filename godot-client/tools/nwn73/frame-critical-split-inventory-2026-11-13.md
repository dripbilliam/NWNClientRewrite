# NWN-73 frame critical CPU split inventory

The saved 240-frame window in `reports/native-tracy-frametime-20261110-reviewed-a.json` reports mean `callback_particles` 2.794 ms, `callback_rigs` 1.542 ms, `callback_effects` 1.480 ms and `callback_world` 0.927 ms. These are serial callback spans from that older workload, not additive proof of a current FPS limit. The more recent quiet world census in `tools/nwn78/persistent-world-checkpoint.md` measured ten motion rows, two active, and ten pose-input visits; it does not establish a profitable worker batch.

* Particles: `systems/native_render/particle_stream_group.gd` already has an opt-in geometry-worker path. Its correctness and performance acceptance belongs to the active particle lane; duplicating the worker here would collide with that work.
* Rigs: `systems/model_rigs.gd:_update` advances live `AnimationPlayer` nodes and publishes skin/attachment state. The completed-player skip failed exact restoration of externally edited animated nodes (`tools/nwn65/finished-player-skip-rejection.md`). A detached worker batch is not source-proven.
* Effects: `systems/native_render/effect_world.gd:258-315` advances child controllers, routes queued events and enters `visual_world.gd:285-320`. That latter loop selects after each individual phase update and can attach/detach models. It cannot be reordered into a parallel whole-effect batch without an exact action/side-effect boundary. The saved `effect_selection_total` mean is 0.429 ms inside the 1.480 ms effect callback.
* World: `systems/network_motion.gd:379-479` mutates movement state, calls support/facing providers and publishes synchronous position notifications. `live_world.gd:625-680` then reads the current state and writes nodes, combat and effect observers. Copying all ten quiet rows to a worker and joining before publication has no demonstrated critical-path saving. The triple readiness check is only inside `world_readiness_and_borders_ms`, 0.011 ms mean in the saved window.

**Next implementation milestone:** the existing particle geometry worker now has bounded original-resource and current attachment-clock headless parity evidence in `tools/nwn64/geometry-worker-original-acceptance-2026-11-13.md`. It remains opt-in pending remaining original effect families, graphical parity and a matched live performance gate. It is the only substantial measured callback here with an existing compute/publish split. For a distinct NWN-73 motion worker, first require a source-pinned capture with materially more active independent rows and an oracle for synchronous position-notification order. No new production worker route or flag is justified by the current evidence.
