## Research options outside normal launch

These are visible so benchmark-only selections cannot be mistaken for production integrations.

- `--particle-random` (benchmark-only): V4 used native selection and a different pinned particle DLL. Normal-launch support/capabilities must be proven separately.

- `--particle-clocks` (benchmark-only): V4 used native clocks; copying a flag is not proof the current kernel implements it.

- `--particle-pose-leases` (benchmark-only): V4 selected managed leases. Current-source and kernel parity must be verified before normal forwarding.

- `--highlight` (native-entry-only): V4 selected whole-character; ordinary host currently does not expose this option.

## Verification contract

Startup manifests record requested selections, actual executable SHA, current-source signature, engine arguments, forwarded native arguments and native capability/thread/owner observations. Unavailable explicit capabilities must reject instead of silently falling back. World admission supplies collision/light owner evidence; that is distinct from startup class availability. Ordinary, streamed and merged loading do not themselves choose a render-thread mode or native engine.
