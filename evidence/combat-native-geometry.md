## Trigonometry and independent comparison

Native CRT sinf `140c7a2b0` and cosf `140c7ac70`: `live-native-sine-cosine-asm.txt`, `live-native-sine-reduction-constants.txt`. Finite f32 inputs |x|<=32 use native range reduction/polynomials. Both SSE and FMA paths are evaluated; software fused arithmetic rounds the exact product-plus-add once. The return is used only when the two native dispatch branches agree at f32 precision. Large-angle remainder routines, errno/exception state and unknown process dispatch are not guessed. Two observed small-angle cos inputs legitimately differ by one f32 unit between the native paths and remain explicit failures.

`capture-crt-math.py` calls **installed Windows ucrtbase.dll**, never game code. `verify-native-math.mjs` compares 30,013 deterministic inputs (signed zeros/subnormals/quadrants plus sampled finite angles) against this independent reference. **60,024 outputs match; two cosine outputs are diagnosed dispatch disagreements, each with a native branch matching the reference.** This is not an exact-game-CRT oracle and does not validate full movement or encounters. Capture/check: `native-crt-math-reference.json`, `combat-native-math-reference-check.txt`.
