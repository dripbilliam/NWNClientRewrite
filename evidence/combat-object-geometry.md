## Integration and validation

NativeAreaObjectGeometry lazily builds initial storage using canonical registry objects and active resources. Queries diagnose changed membership/position/bearing/appearance before returning stale geometry. This guard does **not** implement dynamic native AddToArea/Remove/SetPosition/subarea behavior. Door resting-state changes select live state arrays. Geometry failures enter persistent session/resource diagnostics.
