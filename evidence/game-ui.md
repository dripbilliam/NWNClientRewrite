## Implemented presentation

`NativeUiAssets` loads GUI trees and rasterizes actual MDL geometry/UVs in an orthographic source-XY scene. Up/down/check poses use decoded animation tracks with native XY transforms, separately from world-coordinate conversion. Textures, models and fonts are released on replacement. GUI labels use authored alignment/colors; controls include buttons, editable fields, provider-list/text shells, checkbox switches and sliders.

`GameUi` provides the gameplay HUD, portrait/HP (initially placeholders; now backed by optional BIC import), quickbar, message/system log, chat request input and shared panel navigation. Principal panels are journal, inventory, character, map, spellbook, options, conversation, store, barter, party and examination. Tools retains resource/area/rendering controls and preview selectors for those panels and all native GUI layouts. Common menu/options/character-generation controls navigate between native resources; missing engine-backed actions emit explicit `[UI placeholder]` requests. See the subsequent [BIC/character checkpoint](player-character.md) for real character data and remaining stat/effect limits.

Modules open in Game UI view. J/I/C/M/B/O open journal/inventory/character/map/spells/options. Escape closes nested windows, cancels a queued world action when idle UI permits it, or opens options. The radial owns input while active. Panel/chat input clears held movement and captures input; panels do not pause the world's scheduler. H toggles the HUD; Tools returns to the development interface. With game data loaded, Game UI can also open the native main menu before selecting a module.

The journal projects the existing player's `journal` through module JRL definitions; there is no duplicate gameplay state store. Entries expand/collapse, filter by End and sort by name/priority/received order. Notes persist only for the loaded module session. Quickbar pages retain numeric OBJECT_ID references; selected doors can be assigned to use and other selected objects to examine. Deleted targets are rejected. F1–F12 activate slots, with Shift/Ctrl alternate pages. Door requests use the existing action queue; radial Examine now opens the authored description panel.

## Validation and boundaries

80 unit tests pass, covering TLK bounds/localization/custom StrRefs, journal projection/completion, presentation state, quickbar IDs/deletion, native widget classification, XY geometry/UV hooks and UI animation poses. Resource auditing parses all 104 layouts and the 172 available referenced models. `--check-ui --full-scene` renders all 104 layouts and exercises keyboard/pointer input, eleven completed journal entries with text, notes, movement capture, gameplay panel shells, and the main menu → new game → character generation → gender navigation route. Scripted Angmar/Brogan round-trip and radial open/close/nesting/placeholder/examination checks pass after UI integration. Captures and logs are under ignored `backups/animations/`.

This is a UI foundation covering the installed catalog and principal panel families, not full game UI/gameplay parity. The preview PC still has no loaded BIC stats, portrait or inventory; missing values show unavailable. Character creation/rules, inventory actions, spells/feats, dialogue, stores/trade, parties, audio options, saves, networking and movies remain explicit placeholders. No chat is sent to external users. The map is a live walkmesh/door/player overview, not native explored-tile automap. Notes/quickbar are not saved; native world pause is not implemented.

Further accuracy work includes native hook-based content bounds, atlas state selection, exact font/glyph behavior, control-specific ranges, list providers, tooltips/focus/dragging, UI scaling modes, complete keymap remapping, action queue/status HUD, portraits/HP/effects, minimap/fog and server-driven UI updates. Slider draft values are normalized presentation values, not verified native setting ranges. First menu/character-generation routing is not proof that each workflow's validation and rules are reproduced.
